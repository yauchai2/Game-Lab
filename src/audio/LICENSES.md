# Idle Hero audio sources

All selected source assets are **CC0 1.0**：https://creativecommons.org/publicdomain/zero/1.0/ 。Source licenses allow commercial use and adaptation. Credits remain available in the game and repository. No Nintendo／3DS soundtrack or recording is included.

- **Dream Static** — symphony（https://soundcloud.com/symphony），released 2007。Source：https://opengameart.org/content/dream-static 。Page lists CC0 and asks for credit；credit retained here and in game。Original file：cubedcanada+dreamstatic.mp3。`drift.mp3` is a 72-second excerpt with filtering、loudness normalization and end fades。
- **Dream（Ambience）** — TokyoGeisha。Source：https://opengameart.org/content/dream-ambience 。CC0；source says no credit necessary。`haze.mp3` is a 72-second excerpt with filtering、normalization and fades。
- **Retro Game Music Pack，Level 3** — Juhani Junkala。Source：https://opengameart.org/content/5-chiptunes-action 。Archive INFO explicitly releases tracks under CC0。`rush.mp3` is a filtered、normalized excerpt with fades。
- **Interface Sounds 1.0** — Kenney（https://kenney.nl），2020-02-11。Source：https://kenney.nl/assets/interface-sounds 。Archive License.txt：CC0，commercial use allowed。Selected effects normalized to mono MP3；runtime playback-rate changes distinguish digital combat and device cues。

`provenance.json` records selected original file hashes、derivation settings and shipped hashes。Original large archives are not shipped。`tools/pack_audio.py` embeds the shipped MP3s；runtime playback does not contact the source sites。
