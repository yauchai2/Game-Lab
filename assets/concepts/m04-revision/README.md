# M04 clean revision — concept only

2026-10-26. Alan authorized directly revising M04, then specified: semi-lowpoly, faceted planes, full object centered, Y2K / PS1 / Dreamcast, chunky simplified forms, flat shading, unlit, matte, no texture detail, isolated on solid white. Subsequent「繼續做」authorizes this corrected sheet.

Source: original M04 front/right/back in assets/references/monster-concepts. Host-native ImageGen first produced a textured blue/ivory/orange revision, then edited that sheet to remove texture, decals, scratches, grille pattern, floor shadow and typography. The original generated clean output is preserved byte-for-byte here, not an exported 3D model.

Generation direction: preserve two adjacent speaker cabinets, four dark drivers, short ivory arms, two bent chunky legs, broad shoes, black joints, blue body and tiny orange controls. Three orthographic views front / right (facing left) / back, consistent scale, pure white. Broad planar facets, discrete flat face colors, unlit matte appearance. No texture, grain, dirt, wear, decals, striped tape, logos, screws, tiny details, PBR, reflections, AO, cast/contact shadows, gradient lighting, titles or labels. Simple geometric speaker rings, recessed side handle, broad back vents and short secured cable loop. No face, weapons or added limbs.

Visual review: substantially simplified, with the textured grille, scuffs and tape removed. Image generation still depicts some soft shading/occlusion around speakers and joints; this is NOT proof of strict unlit rendering. Actual model must use unlit flat vertex/material colors, without texture maps, baked lighting or AO. Keep this distinction in downstream Blender/game work.

Status: revised design candidate delivered; not a GLB, not installed into gameplay, not a final approved four-monster mapping. No other monster has been redesigned in this step.
