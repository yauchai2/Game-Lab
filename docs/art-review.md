# 美術方向總檢討（2026-10-20）

對照參考圖（`3D (17)` 到 `3D (20)`，Jet Set Radio Future、Hinata 一類的千禧年 3D）與目前遊戲畫面，找出差距並排優先順序。

## 參考圖的共同特徵

- **角色偏高挑**：約 6 到 7 頭身，四肢細長，手指與腳都有造型，不是方塊。
- **平滑與切面並存**：臉和手臂是圓潤的，衣服、頭髮、機械件才是銳利切面。
- **高飽和的小面積重點色**：薄荷綠、粉紅、鮮黃、天藍，搭配大面積白與灰。
- **乾淨的背景**：純白或棋盤格地板，加上波點與圓形字標，沒有複雜場景。
- **配件密度高**：耳機、護腕、滑板、貼紙、襪子條紋，每個角色都有三四個辨識點。

## 目前的差距

| 項目 | 現況 | 差距 | 優先 |
| --- | --- | --- | --- |
| 怪物與首領 | 圓胖、可愛、偏卡通 | 與主角風格斷裂，也是「太幼兒」的主要來源 | 高 |
| 主角比例 | 約 4.5 頭身，褲子寬、上身短 | 仍偏方塊，腿太粗、手太短 | 高 |
| 臉部 | 只有一對眼睛 | 缺眉毛、鼻、嘴型變化與受傷表情 | 中 |
| 場景 | 草地方塊加街景道具 | 少了棋盤格、波點、霓虹招牌這些千禧年符號 | 中 |
| 背景 | 淡藍天空與像素白雲 | 乾淨但沒有個性，遠景城市太淡 | 低 |
| 介面 | 泡泡視窗、糖果按鈕 | 氣質合適，但缺圓形字標與波點底紋，天賦盤與圖示未改 | 中 |
| 色彩 | 柔和粉彩為主 | 重點色不夠飽和，整體偏淡、偏甜 | 中 |
| 特效 | 平塗球與環 | 尚可，之後補拖尾與衝擊閃光 | 低 |

## 建議的優化順序

1. **怪物與首領改用 Blender 重做**（骷髏與巨獸已完成：反戴帽的螢光外套骷髏、路障機器人與停止標誌，首領換紫色加王冠；史萊姆尚未改）：改成瘦長、帶機械或街頭符號的造型（例如拿路障的骷髏、塗鴉噴罐機器人），顏色提高飽和度。
2. **主角比例微調**：腿拉長、褲管收窄一些、上身加長，手指與鞋頭更清楚。
3. **場景符號化**：地面換成棋盤格，加波點牆、霓虹招牌與貼紙，保留藍天。
4. **介面補齊**：圓形字標標題、波點底紋，天賦盤與圖示統一風格。
5. **臉部與表情**：加眉毛與嘴型，受傷、施法時換表情。

## 取捨

- 提高飽和度會讓畫面更接近參考圖，但與先前決定的「柔和粉彩」有衝突，建議只提高重點色，大面積維持柔和。
- 平滑與切面並存需要在 Blender 內分別處理，工作量比現在的全平塗高，但是最能拉近參考圖的一項。
