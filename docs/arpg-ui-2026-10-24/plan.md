# 角色、背包、天賦工作區重設

日期：2026-10-24，香港時間。依 Alan 本次三張參考截圖；參考名稱只記錄在內部 docs，公開更新日誌及遊戲文字不提研究來源。

## 設計決策

以 POE2 截圖的頁面結構、資訊先後與配裝操作為主要依據。延續本作 Y2K 藍紫窗口、像素字體與數位裝置圖示；將功能區做成深藍液晶面、金屬分隔，不搬用石雕、宗教造型或參考素材。今次取代角色頁「大型封面優先」的預設結構：角色展示及個性保留，但預設首屏以角色能力為主。

目標用戶是時間有限、常用手機檢查掛機收益與配裝的玩家。三個工作頁的共同任務是「看懂目前狀態 → 選擇改動 → 看差異 → 執行」，不靠滑鼠懸停或小字截斷。

## 現況與問題

以 main 122a4c4 的實際來源為基準，使用本輪 before-* 截圖記錄手機與桌機。使用者截圖為參考來源，未宣稱另行登入或實玩 POE2。

1. 角色：既有舞台突出個性，但能力摘要排在舞台與配裝後面；找護甲、攻速或元素增傷須再展開。應改為身份列、重要讀數、防禦讀數、分類詳表。
2. 背包：分類、部位、排序各占一整行，穿著欄不在背包頁；選物品在網格前插入長卡片，令原位置下移。應加入七部位配置與密集網格，點選以共用詳情 dialog 比較。
3. 天賦：全盤縮成 160px 點陣再放大，點一下即花點數；遠端核心與代價不容易研究。應改為可捲動／平移的大盤面，點選只看詳細效果與數值預覽，確認後才分配。

## 角色頁

| 區域 | 參考結構的轉譯 | 本作真實資料 |
| --- | --- | --- |
| 頂部身份 | 左身份、中央角色頭像、右進度 | CHARS、玩家暱稱、等級、深度、已用天賦點 |
| 四個主要讀數 | 同列讀數，名稱／圖示／數字固定順序 | 最大生命、單體直傷預估、暴擊率、生命回復 |
| 防禦摘要 | 三個較次要讀數 | 護甲、護甲減傷、生命偷取 |
| 分類詳表 | 各組小標、對齊數值與單位 | 生命、防禦、攻擊、元素增傷、目前技能 |
| 後續內容 | 清楚分組而非等比卡片堆疊 | 專技／被動、角色展示、故事、個人資料與事件 |

不顯示不存在的魔力、精神、力量／敏捷／智慧總值、格擋、抗性上限或裝備需求。元素欄明寫「傷害加成」，不能冒稱抗性。DPS 保留「預估」，生命回復明示基礎值，技能列用實際 hit／cooldown，不捏造戰力評分。

## 背包頁

- 頂部為配裝裝置：七個真實能力欄：頭部、身體、手部、飾品、鞋子、武器及副手；不新增不存在的藥水欄。
- 每個穿著欄顯示實際縮圖、部位、稀有度與名稱；點擊仍走既有裝備詳情與角色限制。
- 中段資源帶顯示金幣、零件、電路點數；一般裝備／傳奇核心切換、部位及排序集中處理。
- 網格手機 6 欄（320px 採 5 欄確保點擊範圍）、容器足夠寬時 9 欄，每格以圖示、稀有度邊框、等級和穿著／保管狀態作摘要，完整名稱透過可讀標籤與點選詳情取得。
- 每頁 36 件，保留既有容量、分頁、排序、收藏唯一引用與保護規則。固定單格視覺，不假裝新增多格佔位／拖放庫存系統。
- 點擊物品打開共用 modal，候選與穿著物品並列詞綴及數值差異；手機可直排。回收仍需確認，受保護物品不能回收。選取不造成底下網格改位。

## 天賦頁

- 六方向與所有節點完全來自 TREE；既有總點數上限、最多兩個韌體、連接規則及代價不變。
- 主盤採深藍液晶底、六支線分區、清楚的已選路徑與遠端韌體；大型盤面可平移／捲動，提供方向與縮放按鈕，無拖曳操作亦能研究。
- 節點使用原生按鈕。點選僅改暫存 selected；不扣點、不分配。詳情列出效果、連接狀態、韌體代價與實際計算的生命／直傷預估差異。
- 主頁不展示預算／韌體長說明、退點清單或出手策略；只在選中節點時顯示必要詳情。
- 「分配 1 點」再次使用 canAllocateTalent／allocPass 驗證；「退回 1 點」沿用 refundTalent，不能切斷其他節點。城市遠征／訓練限制照舊。
- 搜尋本地節點名稱及描述，有即時清除及無結果提示；搜尋不寫存檔，不隱藏已選路徑。另有可操作清單，方便窄屏及鍵盤。
- 平移／縮放／選取是 UI 暫存，重新 render 保留工作位置；非無限 canvas，不新增 WebGL context。

## 落地與驗收

1. 擷取三頁手機／桌機現況，核對 canonical owners 與並行工作。
2. 實作共用深藍資料面、分類數值列與裝備部位圖，連回既有入口。
3. 實作角色能力表與背包網格／比較，檢查真實數值、空欄、長名稱、核心角色限制。
4. 實作天賦大盤／選點預覽／搜尋／分配及退回，驗證零點數、斷線及挑戰鎖定。
5. 瀏覽器檢查 320、390、768、1440px 與橫向短屏；鍵盤、取消、焦點恢復、減少動態、存檔不變性及 sibling 技能頁回歸。
6. 重建字體與可離線單檔，提交並推送獨立 PR。這次要求為規劃與優化，完成可審閱候選，不沿用上一輪 release 任務來自動發佈。

- 舊 armor／ring 鍵保留；頭戴專裝及持有手機／寵機移至合適部位。equipmentVersion:2 標記完成遷移；收藏、備用裝備、地上物品與構築引用一起調整，原詞條不重抽。
- 天賦頁做減法，取消前置的完整預算卡、六種韌體說明、退點清單及出手策略。只留構築 1／2／3、儲存、可用點數、必要盤面工具；選中節點才出詳情。操作說明與鍵盤替代控制收在末尾，不擋主盤。
