# 固定職業、昇華與可取得電路板

2026-10-24，香港時間。基於 main c7605a6／公開 v0.45.0；Claude e0b3468 已在主線。本輪交候選，不自動發佈。使用者重複貼上的要求合併為八項，全部實作。

## 固定決策

- 四個舊存檔鍵仍為 street／frost／beep／volt，但顯示為脈衝衛士、頻譜遊俠、訊號獵手、寵機技師；模型鍵不改。沒有預設人物本名，新角色必須輸入玩家名稱。
- 每一角色固定一個職業，不可透過選角、構築、存檔 UI 中途轉職。角色列表最多十二個，各自進度、裝備、技能、電路板與昇華獨立；已有單角存檔首次保存包成角色列表。另開角色可取消返回，不覆蓋舊角色。
- 每職業三個昇華；Lv20、最深8層及10次關主討伐後開放。首次選擇免費，同職業昇華可在非挑戰時以每級500金幣重選並確認，不改基礎職業。
- 技能只在電源起點、逐格合法線、對應終點全數接通時進入實際戰鬥清單。顏色是配件分類，配件只可放同色洞；不保留同色線額外×2，階級倍率改1／1.35／1.65，耗電1／2／3。
- 新手3×3，中期4×4，後期6×6，大後期8×8為內部可用格，不含外圈端口。每尺寸兩種經驗證版型，橫／直方向、端口、洞色與障礙配置不同；有限供電3／5／8／12與每技能最多三配件，避免大板只是無限制乘算。
- 板在戰鬥中實體掉落，符合進度的三次關主保底新板；重複轉零件。不自動換板，切換新板為空白，先前手動配置可保留並再次驗庫存。舊8×8板作遷移保留，不重新抽取物品或吞配件；不合顏色／超供電配件回可用庫存。
- 所有新舊自動裝備、預設接線、自動接線、尋路接線與自動配置入口取消；普通攻擊及掛機戰鬥保留。新手明示先裝技能再逐格拉線，沒有偷偷補線。
- 排行榜依職業篩選，快照含昇華及板型，示範仍明示；沒有假設全球服務已接入。角色頁恢復中心3D、每60秒一圈與原待機動作，減少動態停轉。

## 十二昇華

脈衝衛士：接地鐵衛（護盾／生存，專技傷害代價）、電弧破陣（更多跳電，單體代價）、超載鬥士（攻速／頻率，回復代價）。
頻譜遊俠：回聲奏者（弱化本體、一次延遲回聲）、靜域調音師（短凍結，遵守關主控制上限）、疾拍行者（更長連擊節拍，生命代價）。
訊號獵手：定頻狙手（少量高傷鎖定）、分流追獵者（更多弱化鎖定）、殘影速行者（閃避／攻速，生命代價）。
寵機技師：雙核馭機師（更快主機與次目標，生命代價）、維修監督（修復／生命，寵機傷害代價）、熔核改裝師（較慢直擊、鄰近濺射）。

不單靠百分比命名，必須在實際專技／寵機或戰鬥函式接上行為。所有修復共用既有回復預算，控制共用 applyFreeze；不另設不受限回復或永久控制。

## 平衡風險與處理

現版 syncBoard 將未接通技能加入 G.slots，必須修正；現版配件階級與同色×2乘法疊加，單線99配件上限等同無限制，必須改供電與三配件上限。純隨機版面可能無解，因此先用經路徑檢查的版型；同尺寸不調稀有度或直接傷害，差別在布線／洞色取捨。大板有更多可選技能，但共用出手容量仍在，並非六技能同時施放。

驗證要涵蓋全部版型可達、斷線／偽線／交叉拒絕、所有寶石同色／錯色／階級耗電、十二昇華單體／群體／生存、職業鎖定、角色切換與新舊存檔、手動裝備、獨立掉落與離線、排行榜異板只讀、3D減少動態及手機操作。平衡結論區分可量化數值與真人長期體感。
