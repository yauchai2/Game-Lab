# Hello, Static! v0.80.0

將先前停留在素材與樣板的更新接入正式遊戲：

- 四位角色同場3D選角，點選人物或職業鍵、旋轉、命名；無WebGL亦可建立角色。
- 十二款怪物完整倒下動作，掉落與通關維持即時；薄血條優先顯示重要敵人，可在設定關閉。
- 修正寬螢幕金幣／預估DPS遮擋，統一打造用詞並移除重複入口與角色口號。
- 整理移動出招、翻滾與震動；序章紙張／膠紙與圖片共用像素密度，移除舊背景。
- 更新開始與工業配樂，普通精英延續地區音樂；修正返回角色、切景與延遲音效。
- 保留系統記錄、舊傳奇存檔修復、獨立角色存檔與54音訊授權來源。

[直接試玩](https://yauchai2.github.io/Game-Lab/)。已有角色可續玩，更新前可在遊戲內匯出備份。附件idle-hero.html為離線單檔，約44MiB。

本機完整QA、日常回歸與新增整合流程通過。真機Safari／iPad、主觀聽感及長期平衡仍需實際試玩；詳細測試與範圍見docs/release-0.80.0/integration.md。
