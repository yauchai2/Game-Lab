# 現行怪物與吉祥物設定（唯一文件入口）

核對日期：2026-10-26，Asia/Hong_Kong。核對基準：main `a428ceb529f13204e883c1b022db25f34b12b62d`；v0.64.0 發佈狀態另見 [發佈紀錄](release-0.64.0/integration.md)。本次只整理文件，沒有替換素材或修改遊戲。

## 結論與適用範圍

**現行街頭風格使用 12 個基礎模型：M01–M08、B01–B04。** 使用者本次提供的十二款總覽與映射表和現行程式吻合。這十二款已有素材與三視圖，不能因本對話要求「先看單視角」就誤記為從未製作三視圖。

本對話另生成的「13 種一般怪物＋3 種守關者＝16 款」依據舊敵人名稱作畫，屬於**錯誤設定試稿，作廢，不納入正式名單**。其中的硬碟蟹也不例外。保留檔案只供追溯，不匯入正式素材 catalog、不代換現行模型、不據此新增待辦或宣稱使用者已批准造型。

## 不再混用的三種資料

- **玩法類型**：`m.type`、`MTYPES`、`MONSTER_GUIDE` 仍供 AI、圖鑑、數值、碰撞、掉落及舊模式使用。`slime`／`skel`／`crab` 等鍵不能按字面推導現行外觀，也不能為了統一文件改掉這些鍵或存檔。
- **現行造型映射**：`STREET_CREATURES`、`streetCreatureBuild` 及模型 catalog。22 個 type 共用十二模型；不能當成 22 款獨立設計。
- **歷史試稿**：原史萊姆／骷髏／蠻牛，以及巡山機／搬運機／鐘樓看守的三款首領描述。它們可解釋舊版本，不構成現行造型清單。

## 最新材質與展示要求

Ice Cream.mp4 為全遊戲創作基準；細節見 [creative-direction.md](creative-direction.md)。semi-lowpoly、清楚剪影與大塊切面、Y2K／PS1／Dreamcast、chunky simplified forms、flat shading、unlit、matte、no texture detail；超級簡陋、有人味。單件素材完整置中、純白背景；遊戲場景沿用地區背景。

保留十二款的物件身份、輪廓與映射，不能把更新材質風格解讀成另創一套怪物。最新修訂不使用卡通笑臉；設備狀態由幾何燈槽與非對稱指示燈表達，不能用幾何重做笑眼、嘴巴或腮紅。舊參考與輸出保留，不反過來覆寫最新要求。

## 吉祥物／同伴

**名字：Mimo**（讀音「咪莫」，/ˈmiːmoʊ/）。全遊戲隨行的黃色收音機機械人；英文顯示名固定用Mimo，不全大寫，也不另設縮寫全名。四個字母、兩個音節，輕巧圓潤，配合歪殼、短步及小跳的可愛感。這是依本輪命名要求補定的設計名字，不是原參考作品角色名；遊戲顯示文字尚未接入。

**對象已確認（2026-10-28，Asia/Hong_Kong）：** 使用者說「吉祥物機械人可以可愛啲」，並澄清是全遊戲跟隨玩家的吉祥物；不是機偶師的起始戰鬥機偶，亦不加入十二款敵人名單。

**現用實作：** 黃色切面收音機殼、偏置天線／調諧槽、側置旋鈕及喇叭槽，見[設備精修證據](style-complete/device-refinement.png)。`src/game/04-render.js`的buildMascot／mascotUpdate沿用現行跟隨、慶祝及章末標記；本輪未修改程式、模型或素材。舊精修曾記254三角面，屬現用版本證據，不是新方案面數。

**最新可愛化文字方案：**

- 保留黃色收音機機械人身份。上方機殼像大頭，佔可見高度約三分之二，下面收成短底座及兩隻短而寬的方腳；整體仍是很小的隨行物，不擋角色、掉落或預警。這是本輪設計比例提案，非已驗模型尺寸。
- 主機殼用少數鈍角切面，前方一個偏心調諧槽；側面保留一個大旋鈕及三道喇叭槽。短短偏心天線頂端一個小鈍塊，建立略笨拙的輪廓；旋鈕放側面，不能變成一對圓耳。
- 黃色沿用現用基色，暖白小面／墨藍底座讓形體乾淨；不加寫實刮痕、金屬光澤或毛絨質感，維持非常低面、flat／unlit matte。可愛感來自大殼短底、小腳與姿態，保留機械感。
- 表演方向：停下先歪殼看玩家、等一下才跟上，轉身用短步；沿用慶祝事件時小跳兩下、落地晃一下。這些是後續表演提案，不新增必須互動、餵養、養成、獎勵或戰鬥能力，不阻塞原跟隨。
- 指示仍用單一狀態燈／偏心槽及天線方向，不加點眼、微笑嘴或腮紅。更可愛不恢復此前作廢的圓耳笑臉精靈；玩家主角的卡通大眼規格不套用到設備。

後續須驗側後跟隨不遮擋、白底／街景小尺寸剪影、歪殼及小跳可讀性，以及原跟隨／慶祝／章末標記回歸。當前只文字設計，未生圖、建模、改玩法、合併或發佈；機偶師起始機偶保持其獨立設定，見[角色設定](characters-current.md)。
