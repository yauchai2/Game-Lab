# 手機物品網格與設定控制格：0.31.0

Alan 要求參考提供的介面參考圖，讓小螢幕能快速瀏覽所有道具、裝備及設定。本批實作沿用既有 Y2K 像素掌機，不引入參考遊戲的美術或遊戲機制。

## 參考與取捨

檢視壓縮檔共十六張畫面，重點是 03-backpack-equipment、06-skills-grid-active、07-skills-grid-support：小格顯示圖示、等級／數量與狀態，完整資訊集中於選中詳情。檔案沒有設定頁截圖，設定網格是依 Alan 的明確需求，採同樣的資訊分層方式設計。

- 倉庫：一般裝備與傳奇核心共用入口，部位篩選，每頁 36 格，沿用原最新取得優先排序。穿著／上一件／鎖定／構築保護／腐化等狀態有文字；點格子使用原有比較、換裝及回收流程。200 件普通裝備及九款核心的持有規則不變。
- 角色：三個穿著部位並列，核心收藏九格可展開；所有屬性與特殊效果可點開，不用長列表反覆捲動。
- 機件：技能與輔助配件三欄、卡匣兩欄。數量、形狀、使用狀態保留；完整效果由選中詳情呈現。未持有／未解鎖／已使用的機件也能點開說明，沒有直接授予物品。未鑑定卡匣只顯示提示，裝上才鑑定。
- 地圖：十五張上限沿用可自動增欄的物品網格。先看等級與挑戰詞綴數，點開地貌／完整詞綴／獎勵再進入。取消不消耗；確認時重驗地圖及挑戰狀態。
- 設定：兩欄控制格直接列出目前模式、守關者條件、拾取門檻、音效與工具。選項打開橫跨兩欄，沒有窄小的欄內彈出框；畫面與觀戰共用網格與既有滑桿。
- 手機：倉庫、設定與既有戰鬥／打造頁，沒有自訂大小時預設小戰場。玩家曾設定大小則尊重原值；六個主入口、觀戰、原生文字及輸入不變。

## Owner 與驗證

外觀及網格幾何：05g-layout.js 的 UI_LAYOUT_CSS。共用物品格：uiItemTile／uiGearTile；詳情：uiInspectGear／uiInspectCore／uiInspectEquipped／uiInspectMap。機件選取仍委派 pzHold／equipCart。設定摘要為 uiSyncSettings，原選項執行由 core.js 的 mountFigure 擁有，完成後透過 onChoiceChange 通知；觀戰偏好仍由 viewApplyPrefs／viewSavePrefs 擁有。UI_MAP_PENDING 在取消／Escape 清空，過期及重複確認不消耗地圖。

新測試 tools/test_grid_ui_browser.cjs 涵蓋 320／390／768／1440px；手機 390 使用 DPR 3。完整動作包含分頁／刪除後夾頁、部位與核心分類、穿著保護、鎖定／換裝、回收取消、點選焦點返回、未解鎖說明、卡匣鑑定、地圖預覽／取消／過期／挑戰占用、設定變更、鍵盤關閉、重載及 resize。純 UI 檢查在場景就緒後停止持續繪製，需要時明確畫一幀；不拿此結果當手機 FPS 的證明。

既有 UX／布局／收藏／擴充／觀戰回歸與字模、邏輯、strict audit／DESIGN lint 的輸出及前後截圖保存在 grid-ui-v0.31.0/。這是雲端 Chromium，沒有宣稱 Safari 真機、完整報讀器或真人操作偏好已驗收。
