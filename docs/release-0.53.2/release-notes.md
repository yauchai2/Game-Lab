v0.53.2 恢復配件格內的虛線，並改進天賦樹手機操作。

- 配件格內恢復隱約的虛線，順著線的方向流動，接通後更明顯。
- 天賦樹手機改為單指捲動頁面，兩指拖動移動天賦盤，兩指開合縮放。
- 換曲時音樂慢慢淡出再淡入，不再突然切換。
- 「直傷預估」統一顯示為 DPS。
- 角色與怪物頭上的血條變細；我方血條為綠色，敵人為紅橙色，首領為深紅色。
- 模式卡匣改為：點卡匣後彈出視窗，直接選要裝到哪個技能。
- 合成與超頻頁面改為圖像卡片。
- 接線板的上一步、下一步按鈕改為粗線圖示加文字。
- 無限之塔畫面精簡，移除重複的樓層列表，改為大字樓層、進度條與三格數據。
- 昇華職業改用3D圖示。
- 背包與配裝的裝備圖示放大。
