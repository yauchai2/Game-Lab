# 跨對話共用方式

共用來源：https://github.com/yauchai2/Game-Lab

儲存庫保存可查證的規則與工作成果；各對話仍有各自的上下文。專案記憶可輔助接續，重要決策應留在文件中。

## 貼入「專案 → 進階設定 → 自訂指示」

```text
本專案的共用來源是 https://github.com/yauchai2/Game-Lab。
開始工作前，請讀取該儲存庫目前適用分支的 AGENTS.md 與 README.md，再依任務查閱 DESIGN.md、UX-CONTRACT.md、docs/backlog.md 及相關交接文件。
不要假設已讀過其他對話。先確認分支、提交與相關修改，保留其他對話的成果；重要決策與進度寫回對應專案文件，並記錄驗證結果與未完成事項。
區分提案、已實作、已驗證、已合併與已發佈。僅存在本機或其他分支的變更，不代表目前分支已具備。
若無法存取儲存庫或所需分支，請說明限制，不要假稱已完成查閱；在可取得的資訊範圍內繼續工作。
```

截圖中的設定提示「專案指示、來源和記憶僅適用於雲端對話」。使用本機資料夾的對話，應以該 checkout 的 AGENTS.md 作為協作入口。雲端對話則需要具備儲存庫讀取權限與可用工具，指示中的連結本身不會授予存取權。

## 共用紀錄的位置

- 固定協作規則：根目錄 AGENTS.md。
- 專案入口與執行方式：README.md。
- 設計與介面決策：DESIGN.md、UX-CONTRACT.md 及相關 docs/ 文件。
- 任務進度：docs/backlog.md；只更新本次可確認的項目。
- 個別任務交接：相關 PR 描述或 docs/ 下的交接文件。

## 交接範本

- 日期與時區：
- 任務與狀態：
- 分支／提交／PR：
- 修改範圍與決策原因：
- 驗證結果與限制：
- 未解問題與下一步：
- 同步狀態：本機／已推送／已合併／已發佈。

新規則需出現在對話實際使用的分支中，並被讀取才會發揮作用。既有對話可補上一句：「請重新讀取目前分支的 AGENTS.md，依共用協作規則繼續。」
