# 0.32.1 UI/UX review

2026-10-23，依 Alan 的四項要求檢查目前介面與共用程式來源。這份文件區分已實作的修正與尚未取得的瀏覽器證據；不是實機可用性測試報告。

| 問題 | UI/UX 影響 | 修正 |
| --- | --- | --- |
| 全後代字級強制覆寫，手機 18/28、桌機 24/36 | 資料層級被拉平，格子及長說明佔據過多空間 | 正文／輔助／標題分層；手機 16/24、14/20、20/28，桌機 18/26、16/22、26/34；保留像素字模 |
| HUD 額外保留大字幾何 | 小畫面戰場上方空間過多 | 手機等級框 66→48px、上方留白 92→72px；桌機框 82→58px |
| 小格最小高度與新字級不匹配 | 同屏資料減少，增加捲動負擔 | 裝備格 110→94px、機件格 116→100px；保留點開完整詳情及原生按鍵 |
| 手機 3D 固定減半取樣 | 文字清晰，但戰場模型過於模糊 | 自動模式手機中／桌機高，提供低中高及自動；390×260 預設 195×130→292×195 |
| 每次換圖彈出故事卡，並暫停戰鬥 | 重複打斷掛機節奏，將閱讀變成負擔 | 約 0.7 秒戰場掃光，不能攔截點擊、搶焦點或停戰；減少動態直接略過 |
| 多篇故事一次展開 | 不易找到某段內容 | 手記顯示收錄數，逐篇自行展開／收合；新內容靜默收錄，不自動打開 |
| 身體裝扮尚未打算推出 | 入口和掉落過多，超出本階段產品範圍 | 公開清單只留武器、副手、飾品；舊資料保留，停用入口不能扣金幣 |

## 已驗證

- 畫質自動預設、顯式選擇、DPR 獨立性、長邊上限、極端尺寸比例。
- 三類裝扮選擇／購買、重複購買不扣款、停用分類無法修改持有資料、純外觀不改戰鬥能力。
- 換圖不停止 update 時間、沒有文字按鈕與焦點處理；故事保存與重讀資料保留。
- 完整 HTML 內嵌 JavaScript 語法、遊戲機制、裝備、離線、導航等回歸；逐項結果見 review-0.32.1/checks.json。

## 尚待驗收

本機瀏覽器套件下載取得空壓縮檔；雲端瀏覽器拒絕 file: 協定。本輪沒有修改後瀏覽器畫面、手機觸控、Safari 或 FPS 證據。字級與高度為來源設定，不能推論所有裝置同屏件數；需要在 320／390／768／1440px 實際核對溢出、鍵盤焦點、長內容及畫質切換。高畫質的效能代價需以裝置實測，玩家可選中／低畫質。
