# 電路板接線（技能頁，0.33.0）

取代舊的方塊拼圖。邏輯在 `src/game/00-grid.js`（純邏輯、可單獨測試），介面在 `src/game/05i-wire.js`。

## 規則
- 8×8 板：第 0 欄是電源，第 7 欄是技能插槽（列 3、4、2、5、1、6，等級 1、4、9、15、22、30 解鎖）。
- 線從電源旁（x=1）出發，直角轉彎，終點必須是插槽前一格才算接通；線總長有上限。
- 配件貼在已接通的線上，依路徑順序生效，數量上限隨等級（2／3／4／5），標籤不符不生效。
- 同款正交相鄰 ×1.2（上限 1.6），踩中增幅格（Lv6 起）×1.4。壞軌固定，不能走也不能放，不會破壞已建好的 build。
- 不含：觸發條件、技能串聯、電量、詞綴、線序衰減、發熱。

## 舊存檔
`GridLab.adopt` 把舊拼圖存檔轉成接線板：技能依位置分配到插槽，改機模式保留，舊的連結配件依序貼回線上（受上限限制），放不下的留在背包。轉換後傷害不會變低。
