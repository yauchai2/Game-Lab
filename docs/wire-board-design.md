# 現行技能電路板

2026-10-28 按 main `641c43d` 的 00-grid.js 核對。取代舊固定 8×8／階級 1、1.5、2 的 0.33 文件；舊存檔幾何僅在遷移時使用。

- 可取得的板有 3×3、4×4、6×6、8×8 內部可用格，外圈端口不計入；版型、洞色、障礙、端口與供電由 `GridLab` 的 TEMPLATES／layout 管理。
- 每路必須由對應起點逐格合法接至終點才啟動技能；不是接近終點或任意同色相連就有效。新規則的進階板起終點可錯位。
- 配件只入同色洞，每技能最多三枚；階級強度為 1／1.35／1.65，耗電 1／2／3。各板供電以程式模板為準，不再沿用舊線色額外 ×2 規則。
- 裝備、放置、接線由玩家操作；保留撤銷、重做及鍵盤／選單替代。拖線的逐格驗證與輸入狀態見 [UX 契約](../UX-CONTRACT.md)。
- `src/game/00-grid.js` 擁有邏輯，`00-grid-legacy.js` 保留舊資料遷移；`05i-wire.js` 擁有介面。不能因名稱有 legacy 就刪除仍被 require／入口引用的檔案。

驗證：`node tools/test_grid.js`。舊實驗性接線／過熱／串聯方案見 [研究索引](research.md)，不表示已加入正式版。未結的真機拖線手感等沿用 [backlog](backlog.md)。
