v0.54.0 裝扮特效、血跡、詞綴與手機面板整理。

- 裝扮新增「身體特效」：電路光環、靜電火花、訊號波紋、像素星屑，純外觀不影響能力。
- 血跡改為鮮紅色液體：落地後向外擴散，邊緣略深，慢慢變暗淡去。
- 稀有裝備新增「追加詞綴」改機：打造出來的裝備多為 4 條詞綴，可以逐條追加，最多 6 條。
- 手機面板的把手拖到最下方，放開後進入觀戰；點一下畫面回到操作台。
- 移除標題列的「展」按鈕，改由把手控制；返回按鈕改放在標題列左側。
- 離線結算頁加入 3D 低解像自轉標誌。
