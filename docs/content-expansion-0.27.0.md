## 本版功能

- 倉庫 200 件，入口「角色 → 裝備倉庫」，按部位篩選、12 件分頁、屬性／DPS／生命比較、手動換裝、保管鎖定及確認回收。手動穿戴關閉自動換裝，換下物品留存；傳奇維持獨立核心收藏。滿倉保留高稀有度／高階詞綴，僅回收未保護候選，沒有較低候選就回收新物品；過濾門檻與累計回收數明示。
- 普通掉落不再因綜合分數低就立即消失。已穿著、上一件、鎖定、詞綴鎖定及已腐化物品受保護。舊存檔相容；舊版已出售物品沒有憑空重建。
- 金幣與電路點數落地，裝備／寶石／卡匣／地圖也需走近拾取；角色會選擇掉落物前往。相鄰金幣及點數合併為堆，待拾物隨存檔保存，年齡不觸發自動付款。經驗仍按擊殺發放，點數是新的電路貨幣。離線補算照常結算及保留手動選擇。
- 新詞綴 T0–T4；T2／T1／T0 依物品等級 5／12／25 解鎖，T0 機率為 1.5%。舊詞綴依相對值推定顯示，不改原數值。
- 天賦由 40 擴至 100 節點，六向支線及環形互連；超頻協定加急速、減生命，斷線重播加回放、減普攻速度，電池孤注加暴傷、減生命。手機有可連接節點大按鍵清單。
- 四種新輔助：鎖頻晶片（傷害／暴擊換冷卻）、分線器（節流濺射）、備用電池（節流回復）、延遲緩衝（降低傷害換回放）。每 20 電路點數指定合成一件；所有角色可搭配，仍遵守鄰接與標籤。
- 地區由 6 增至 12：新增訊號站、海港、神社、機房、高架及商場，各有不同地標／天空與遭遇池。普通地區每四深度變化，掉落地圖可前往全部地區。
- 新怪物：快速跳線蛛、範圍攻擊音箱、浮游訊號幽靈、重裝硬碟蟹；四種首領輪廓按地區輪替。新增有預警的落點範圍攻擊。
- 出怪間隔由 .35／.8 秒調至 .2／.45 秒，密度按等級／深度提高，實際上限 42。中後段耐久與攻擊倍率增加，首領額外強化；修正原新手倍率的過大懲罰，保留起步曲線。一個非固定亂數的純模擬樣本在 120 秒到等級 7／深度 3，144 擊殺、0 死亡；這不是平衡結論。
- 環、光柱、拖尾、衝擊與拾取收束加強，共用短按鍵亮度／切頁動畫。減少動態及關閉動態衝擊會停用震動／閃光／hit stop；邊緣閃光限頻，沒有快速全屏連閃。

## 手機效能證據與限制

移除 #cv3 邊緣 mask，實際 computed maskImage 為 none。繪製採約 30Hz 上限，模擬以實際 elapsed 推進；打擊停頓不再把 dt 乘 0.1。updateFx 使用最多 160 個 Mesh／材質的物件池，沒有每幀 dispose／new 材質。傳送門靜態部件與裝飾按材質合批。

固定 390 × 844、DPR 3、12 個環形效果、30 幀的 Chromium 微型量測：材質 ID 數 720 → 24，draw calls 312 → 220，scene 呼叫耗時中位數約 5.55 → 2.50ms。這只證明該情境的配置／CPU 工作減少，不是實體手機 FPS、Safari 或包含新增密集怪群的完整效能結論。原始 before／after JSON 隨本文件保存。
