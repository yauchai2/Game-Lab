# 裂隙與操作整合計劃

範圍為backlog RIFT-01至29，單次release。基底fe88546，納入PHONE-01修正4799ed7。

先修共用呈現與狀態：三段像素設定、保留捲動、紅藍綠同源、歷史操作、行動裝置與音量。其次加入可重用3D展台（塔樓／技能），只在可見時繪製，關閉釋放renderer。

原創「斷訊裂隙」：普通冒險地圖可遇見斷訊手，英雄接近才啟動。先擴張並產生限量特殊怪，擊殺降低失控；進入收束階段，需維持擊殺以封閉，超時只得部分碎片。玩家可設定本次追蹤裂隙來引導接近，並非點擊直接領獎。專屬產物為斷訊碎片，可鍛造兩款改變攻擊邏輯的暗金核心；不自動裝備、不取代其他玩法產物。存檔保留未完遭遇與已付獎標記，離線不主動開啟新裂隙。

塔樓維持三種室內房，樓梯移近後側牆且保留走廊；登階持續播放怪物退場及限量血跡，獎勵仍只提交一次。

驗收：針對存檔遷移、掉落與新玩法防重領、顏色及undo／redo、桌面／手機操作、輪盤與雙指、無WebGL縮圖退路、預覽關閉釋放、正式產物雜湊與HTTPS瀏覽器。保留真機與長期平衡限制，不稱全部遊戲已驗證。
