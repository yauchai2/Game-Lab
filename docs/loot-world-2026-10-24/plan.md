# 技能、背包與世界追加

基底main de81f4a／正式v0.47.0；任務分支codex/deeper-loot-world。本次先完成候選，不沿用上一輪release授權。

視覺沿用Cubic 11、銀灰#e6e8f7、深藍#172751、藍紫#303d9b、訊號青#80cebd與琥珀#d4b374。主視覺取捨：以中間加大的身體裝備作背包的組裝核心，兩旁武器／副手、下方手／飾品／鞋，其他操作保持緊湊。

所有裝備回收沿用recycleStored與既有保護；增加「稀有度／部位／物品等級」篩選、精確數量／收益預覽，確認時只處理快照中仍符合且未受保護的物品，新增掉落不混入；保留單件鎖定及構築記憶管理。拾取門檻與清理分開，無自動穿裝。

新增6主動技能及6條件式配件；每項有獨立機制、上限及取捨，接線供電／三配件上限不放寬；沿用傷害、控制、回復額度、計時及離線模擬擁有者。新增魔物用獨立幾何及既有預警招式組合，不僅換色；新增偏工業／礦場／沿岸地區，舊粉色區保留索引改名改色，舊存檔不洗地圖。

序章三頁不同場景；手機改正交等距取景，畫面字模與外殼用共同低解析度語言、保留可操作DOM。圖鑑為個人收集進度，編年史為完整機制參考及開啟時快照，明示差別；編年史共用favicon。像素質感加即時樣本與可辨別靜態紋理，不加常駐昂貴全屏濾鏡。隱藏戰場改真文字及回復顯示按鈕。
