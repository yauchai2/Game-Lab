v0.52.0 更新開局、操作引導與賽季介面，並接通意見回饋及贊助入口。

- 開局使用低解析3D標誌與慢速自轉，保留「開始遊戲」及「略過故事」，支援減少動態。
- 新角色加入三步實作教學：觀察自動戰鬥、比較並換上裝備、手動接通第一個技能。可稍後續接，既有角色不強制重學。
- 手機戰場依頁面自動調整大小，角色、冒險及設定大；背包、技能及打造小，保留手動設定。
- 賽季內容集中一頁，整合裂隙、巡迴、中樞、里程碑及本季核心；裂隙開啟時切換紫色氣氛。
- 簡化角色及冒險重複資訊，來源、全景及手記保留於次級說明；天賦提醒改為紅點。
- 意見回饋可直接在遊戲送出並取得單號；失敗時保留草稿。回饋會公開，請勿填寫私人資料。
- 贊助頁加入Patreon公開入口與簡短作品介紹，自願支持不影響遊戲內容或進度。
