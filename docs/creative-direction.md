### 使用者確認：「酷」的深層含義

本輪使用者原話：「深層的反叛、打破常規的、懶散鬆弛的、黑色幽默、自由、對比，非流於表面的酷。」這是**使用者確認的創作方向**，不是從影片推測的劇情或作者意圖。適用於世界規則、人物選擇、敘事、美術、動作、聲音提案與玩家體驗。

| 準則 | 如何落在創作中 |
| --- | --- |
| 深層反叛 | 人物質疑誰有權決定設備的用途、誰能進某個區域、誰值得得到機會；有自己的底線與替代做法，也承受選擇的代價。 |
| 打破常規 | 廢物可成武器、工作工具可作施法媒介、玩家可組出設計上容許但不直覺的流派；規則與代價仍清楚可學。 |
| 懶散鬆弛 | 平常動作省力、表情克制、留有停頓，危急時做事有效；能力來自經驗與準確，角色有工作以外的生活。 |
| 黑色幽默 | 荒謬的制度與認真執行它的人形成反差；後果留在場景和人物反應，不靠人人講笑話或嘲弄弱者。 |
| 自由 | 人物選擇值得接的委託與值得守的約定；玩家可試錯、保留構築、按自己的時間回來，少用催促與強制流程。 |
| 對比 | 鬆弛人物／突然動作、鮮明日光／陰暗交易、精密規章／荒謬結果、外表普通／能力出乎意料；每個區域與角色有具體反差，不全城同一情緒。 |
