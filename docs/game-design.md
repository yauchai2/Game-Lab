## 現行遊戲重點（2026-10-28，使用者再次確認）

目標玩家是平時時間不多的上班族。自動戰鬥與離線經驗提供持續成長；回來後用有限時間研究武器、技能、道具與攻擊模式的組合。體驗要紓壓，但決策有影響、值得反覆玩。

核心是隨機性、未知新攻擊模式的發現、流派構築與長期解鎖。參考 **POE2／暗黑破壞神2** 的掉落、詞綴與構築深度，以及 **吸血鬼倖存者** 的自動攻擊、密集清怪與組合變化；具體做法須適配掛機，而非直接複製持續手操或重開即清空全部進度。

「上癮心理學」在本專案落實為：不確定的新發現、短中長目標、收集進度與驗證想法的回饋。玩家想回來，是因為仍有組合想試；不靠錯過即損失、連續登入壓力或假裝差一點中獎。這是本次設計取向，不表示現行遊戲已實作以下全部方案。

### 構築循環與隨機規則（優化提案）

**掛機／離線累積 → 回訪看經驗與掉落 → 發現新模式／組件 → 比較並手動配裝接線 → 短試驗 → 保留有效構築與成就進度 → 再探索。**

- 隨機首先改變「如何攻擊」：分裂、彈跳、穿透、環繞、延遲引爆、召喚等為設計例子；逐一核對既有技能／配件／卡匣支援後再選，不能把例子當已存在的功能。
- 輸出形態、作用範圍、觸發條件等有區別，再搭配數值詞綴。避免大量名稱不同、畫面與決策相同的掉落。
- 發現前保留未知感；鑑定後清楚顯示行為、代價與相容條件，換上前提供短預覽。不要靠模糊規則隱藏負面效果。
- 同一攻擊槽先限定一個主要模式轉換，再讓輔助配件修改投射、範圍或觸發；衝突模式明示互斥，允許的組合列明先後順序。不得讓多個轉換默默互相覆蓋。
- 隨機有探索邊界：保留至少一套能用的基本構築，重複物有既有回收／改機用途；若某模式長期不可得，再按實際掉落資料評估分類保底或定向追求。保底／定向方案未定數值、不當作已上線。
- 自動戰鬥不等於自動替玩家做構築決定：沿用手動配裝、接線、收藏與構築保存，離線結算不偷偷換裝或覆寫配置。

### 忙碌玩家的時間尺度（設計目標，待驗證）

| 可用時間 | 本次回來能完成甚麼 |
| --- | --- |
| 約30秒 | 看懂離線經驗、重要新發現與下一步；可立即離開，不強迫逐件抽獎演出 |
| 約3–5分鐘 | 比較一件關鍵掉落、改一項配置、完成短試驗 |
| 約10–15分鐘 | 研究一組模式相容性、比較兩套流派、挑戰一個有意義的目標 |

離線報告聚焦「成長／新發現／卡住原因」，重複低價值物彙整，不把有限遊玩時間耗在清單。日常回訪不要求搶點登入或強制領獎才能繼續成長；實際上限與結算規則仍由現行owner決定，本次未更改。

### 長期耐玩與角色解鎖（提案）

短期追求一個新模式，中期完成一套可運作流派，長期收集模式／關鍵物與完成特殊成就。每次出發累積某項可見進度，不等於每次都發稀有物或跳成就；避免成就只剩擊殺計數與無限加數字。

可研究「首次完成不同模式組合」「用不同流派達成指定挑戰」等成就，獎勵新物品池、候選模式或未來新角色。保留已解鎖／已建立角色，不將現有四職業突然重新上鎖；新增角色應帶來不同決策與構築方向，不是純數值升級。長期解鎖需保留初期基礎流派的可行性，避免物品池愈大愈難找到必要組件。

### 驗收與角色重製的關係

四主角提供不同的起始循環與傾向，不把武器、元素或攻擊模式鎖死在某個角色。人物輪廓固定可辨，持用裝置與攻擊表現可隨構築變化；稀有裝備不能成為基本職業辨識的必要條件。重製依[角色方案](characters-current.md)同步調整。

後續以實際可用的不同攻擊模式數、短回訪完成率、首次模式試用所需時間、重複物浪費與同階可行流派數驗收；不單用登入次數、在線時長或總DPS判斷成功。先核對現行能力，再驗證兩套同職業、不同模式的構築是否有明顯觀感與取捨，並檢查離線結算、配置還原與新解鎖相容性。

## 大改版方向：永久構築與遠征發現（最新提案）

2026-10-28。使用者已明確允許大改。本節取代早期候選方向；允許重構不代表以下機制已實作、已平衡或已發佈。核心支柱維持不變，既有角色／物品／進度須有可核對的遷移路徑。

### 1. 把四種內容分清楚

| 層級 | 玩家在這裡決定甚麼 | 保存／隨機邊界 |
| --- | --- | --- |
| 角色 | 喜歡的人物、招牌循環與擅長的成長方式 | 永久身份與進度，不用每輪重練 |
| 構築 | 武器基底、攻擊模式、配件、裝備及天賦如何配合 | 手動編輯、保存與還原；離線不擅自改動 |
| 遠征 | 要追求哪類發現，願意承受哪種地圖風險 | 分段自動戰鬥，結算後保留成果；能中途離開 |
| 發現 | 下一個模式、關鍵詞綴或收藏會帶來甚麼新選擇 | 隨機內容有價值差異，已獲得／已結算結果不隨開關畫面重抽 |

現有系統先依這四層重排入口、責任與獎勵，優先刪掉重複工序，不再加一層與接線板／模式卡匣做相同事情的新系統。

### 2. 重新分工武器、模式與角色

**武器決定基本手感；模式改變攻擊行為；配件創造連動；天賦強化取捨；角色提供循環偏好。** 七部位物品與已取得資料先保持；若日後改欄位，必須先提出對等轉換及可還原方案。

一套構築至少應回答：怎樣清小怪、怎樣打首領、怎樣保命。用模式與組件解不同問題，而不是全堆最高傷害。一件裝備最多承擔一個主要行為改變，其他詞綴提供支持；不在武器、卡匣、天賦三處重複塞相同「分裂」。

人物可以重新設計甚至修改職業被動，但先有跨流派可用的循環：AKI以承壓／蓄能與釋放為候選方向，MILO以持續命中與週期回放，PING以觀察／精準觸發並兼顧無小怪首領，NULL以裝置協作及資源分配。這些是機制探索方向，不能把待改被動當現行能力；不新增需要手操的反應測驗。

### 3. 讓「抽到新玩法」比「又多一件垃圾」更常被感受到

- 首次發現模式時，提供行為預覽、清楚代價，以及可裝入哪套現有構築；發現與試用之間不再強迫多層升級／鑑定／重洗。
- 候選做法是「模式收藏永久記錄，裝備品質繼續追求」：模式的基本試玩權與高品質掉落分開，重複模式可支援升階／定向研究。先用現有零件／重複物資源驗證，不另開貨幣。
- 能追求的掉落家族與稀有驚喜並存。玩家可選「偏投射／偏裝置」等路線權重，但不能直接指定每次掉哪一件；地圖只顯示真實生效的權重差異。
- 沒抽中想要的模式也累積可見研究進度；按分類抽取或定向補齊的候選成本要由實際掉落分布決定，不先承諾固定幾抽必得。
- 收藏池逐步擴大，但必要基礎件有穩定取得途徑；新解鎖不能只稀釋掉落池。已見模式再次掉落可直接辨識，減少重複揭曉動畫。

### 4. 遠征服務掛機，而非要求玩家跟著計時器玩

遠征以數個小段組成，第一樣板可先以約8–12分鐘模擬進度作調校起點，不是要求玩家在線8–12分鐘。隨時離開後沿用原構築繼續；回來先看已完成段落與實際收益。失敗限制後續推進或效率，不撤銷已結算的收藏、成就與整個角色進度。

出發前最多一個主要取捨：穩定收益、偏向某掉落家族，或較高風險的挑戰。過程不加入離線時一定要作答的升級卡；玩家不回來就按已選路線繼續，不默選新技能或強制停在獎勵頁。第一輪不增加局內臨時構築與額外配點，以免長期研究被每輪清零抵消。

離線同樣有經驗與合理發現機會，經由原結算owner依出發構築、路線及能力快照計算，不能憑空宣稱通過未模擬的首領／操作成就。多次讀取同一回訪不重領；結算與領取狀態要原子保存。上限、速度與收益率先不改，後續按基線測試再調。

### 5. 把維護成本降下來，研究深度保留下來

回訪先呈現三件事：成長了甚麼、有甚麼首次發現、目前哪個問題值得處理。只為真正需要選擇的物品打斷玩家；低階重複物按使用者已設定規則彙整，收藏、已鎖定與被構築引用的實體物品保持保護。

試用新模式時，可把當前構築複製到暫時試驗位，比較後由玩家明確套用或放棄。試驗只讀取／借用合法持有物，不複製資源或派發正式戰利品；保存構築仍引用同一物品。接線板仍有研究價值，但不要求每次換同類組件都重拉一整塊板；先改善局部替換與相容性提示，再決定是否簡化板規則。

### 6. 解鎖的獎勵是「多一種可能」，不是永久數值膨脹

成就優先鼓勵新體驗：兩種不同流派完成同階內容、首次完成一組連動、在某項限制下通關。判定真實裝備與戰鬥紀錄，不能只憑選到模式或按預覽就算完成。

新玩家保證可用起點；後續道具／模式／新角色提供橫向選擇。角色解鎖帶新循環，不天然全面優於初始角色。既有玩家已解鎖角色、已持有收藏不重新上鎖。成就加成的既有投入也不直接抹除；如改為解鎖獎勵，先提供遷移對照與前後可用性驗證。

### 7. 先做一個能驗證核心的可玩樣板

範圍先限 **1角色、2技能、5個現有模式、1小怪路段及1無小怪首領**。使用CHAIN／BEAM，模式候選為CHAIN_FORK、CHAIN_OVERLOAD、BEAM_SWEEP、BEAM_FOCUS、BEAM_CAPACITOR；定義與效果可核對01-data，實際組合及平衡須再測。

| 樣板構築 | 待驗證差異 |
| --- | --- |
| 分叉紅外線＋掃射雷射 | 多目標覆蓋是否明顯、與單體構築有何代價 |
| 過載紅外線＋聚焦雷射 | 單體／直線命中是否有價值，冷卻與清場損失是否可接受 |
| 紅外線命中蓄電＋撥號放電 | 能否看懂「另一技能供能→雷射消耗電荷」的連動，循環不靠說明書才理解 |

先借現用模型驗玩法，不把它當新美術方向；新角色輪廓可平行製作，但完整四人建模應在樣板證明攻擊模式可辨後展開。樣板的模式／資源可用測試工具明示提供，不偽裝真實掉落率或正式玩家紀錄。

必須驗證：回訪約30秒能說出新收穫；首次得到模式後3–5分鐘內能試出差異；同角色至少兩套構築各有適用場景；離線前後收益及快照一致；試驗／還原不丟物或複製物品。新模式數、試用率、短回訪完成率、重複物浪費與各場景表現一起評估，不單看DPS／登入時長。

通過後才擴大模式池、四角色被動、新人物／裝置、遠征選擇與長期解鎖。若差異看不懂，先修改攻擊行為與回饋；若維護太繁，先刪掉重複操作。不要用更多角色或更稀有掉落遮住基本循環的問題。

### 8. 執行與遷移

本次完成架構提案與現有模式定義核對，尚未實作或執行樣板。工具／素材／文件可在本任務分支製作；src/index/dist依目前協作分工由原型討論串接入，不能將寫了規格說成已經改版。交接時沿用既有戰鬥、掉落、回訪、收藏與存檔owner，不各開一套狀態。

先保留資料快照及舊存檔測試，再逐步替換玩法與資產；不清空玩家投入、不覆蓋其他分支成果。現用角色素材按使用者先前確認暫留，等新人物及遊戲接入驗收後移除。未合併、未發佈。
