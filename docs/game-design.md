## 現行遊戲重點（2026-10-28，使用者再次確認）

目標玩家是平時時間不多的上班族。自動戰鬥與離線經驗提供持續成長；回來後用有限時間研究武器、技能、道具與攻擊模式的組合。體驗要紓壓，但決策有影響、值得反覆玩。

核心是隨機性、未知新攻擊模式的發現、流派構築與長期解鎖。參考 **POE2／暗黑破壞神2** 的掉落、詞綴與構築深度，以及 **吸血鬼倖存者** 的自動攻擊、密集清怪與組合變化；具體做法須適配掛機，而非直接複製持續手操或重開即清空全部進度。

「上癮心理學」在本專案落實為：不確定的新發現、短中長目標、收集進度與驗證想法的回饋。玩家想回來，是因為仍有組合想試；不靠錯過即損失、連續登入壓力或假裝差一點中獎。這是本次設計取向，不表示現行遊戲已實作以下全部方案。

### 構築循環與隨機規則（優化提案）

**掛機／離線累積 → 回訪看經驗與掉落 → 發現新模式／組件 → 比較並手動配裝接線 → 短試驗 → 保留有效構築與成就進度 → 再探索。**

- 隨機首先改變「如何攻擊」：分裂、彈跳、穿透、環繞、延遲引爆、召喚等為設計例子；逐一核對既有技能／配件／卡匣支援後再選，不能把例子當已存在的功能。
- 輸出形態、作用範圍、觸發條件等有區別，再搭配數值詞綴。避免大量名稱不同、畫面與決策相同的掉落。
- 發現前保留未知感；鑑定後清楚顯示行為、代價與相容條件，換上前提供短預覽。不要靠模糊規則隱藏負面效果。
- 同一攻擊槽先限定一個主要模式轉換，再讓輔助配件修改投射、範圍或觸發；衝突模式明示互斥，允許的組合列明先後順序。不得讓多個轉換默默互相覆蓋。
- 隨機有探索邊界：保留至少一套能用的基本構築，重複物有既有回收／改機用途；若某模式長期不可得，再按實際掉落資料評估分類保底或定向追求。保底／定向方案未定數值、不當作已上線。
- 自動戰鬥不等於自動替玩家做構築決定：沿用手動配裝、接線、收藏與構築保存，離線結算不偷偷換裝或覆寫配置。

### 忙碌玩家的時間尺度（設計目標，待驗證）

| 可用時間 | 本次回來能完成甚麼 |
| --- | --- |
| 約30秒 | 看懂離線經驗、重要新發現與下一步；可立即離開，不強迫逐件抽獎演出 |
| 約3–5分鐘 | 比較一件關鍵掉落、改一項配置、完成短試驗 |
| 約10–15分鐘 | 研究一組模式相容性、比較兩套流派、挑戰一個有意義的目標 |

離線報告聚焦「成長／新發現／卡住原因」，重複低價值物彙整，不把有限遊玩時間耗在清單。日常回訪不要求搶點登入或強制領獎才能繼續成長；實際上限與結算規則仍由現行owner決定，本次未更改。

### 長期耐玩與角色解鎖（提案）

短期追求一個新模式，中期完成一套可運作流派，長期收集模式／關鍵物與完成特殊成就。每次出發累積某項可見進度，不等於每次都發稀有物或跳成就；避免成就只剩擊殺計數與無限加數字。

可研究「首次完成不同模式組合」「用不同流派達成指定挑戰」等成就，獎勵新物品池、候選模式或未來新角色。保留已解鎖／已建立角色，不將現有四職業突然重新上鎖；新增角色應帶來不同決策與構築方向，不是純數值升級。長期解鎖需保留初期基礎流派的可行性，避免物品池愈大愈難找到必要組件。

### 驗收與角色重製的關係

四主角提供不同的起始循環與傾向，不把武器、元素或攻擊模式鎖死在某個角色。人物輪廓固定可辨，持用裝置與攻擊表現可隨構築變化；稀有裝備不能成為基本職業辨識的必要條件。重製依[角色方案](characters-current.md)同步調整。

後續以實際可用的不同攻擊模式數、短回訪完成率、首次模式試用所需時間、重複物浪費與同階可行流派數驗收；不單用登入次數、在線時長或總DPS判斷成功。先核對現行能力，再驗證兩套同職業、不同模式的構築是否有明顯觀感與取捨，並檢查離線結算、配置還原與新解鎖相容性。

下文為早期歷史設計與候選，不代表目前槽位、離線上限或已實作功能；與本節衝突時以本節目標及現行程式為準。

## 現況（已實作）

- 每波刷怪潮，怪物從島的四面八方湧入，同時存活上限隨等級增加。
- 裝備三格：武器、外套、配件，有稀有度與詞綴，另有傳奇裝備。
- 四個主動技能，每個技能最多兩個輔助寶石，技能槽隨等級解鎖。
- 天賦盤、地圖（含詞綴與深度）、守關者。
- 離線結算，最多 6 小時，回來時顯示報告。
- 自動存檔，每 5 秒一次。
- 升級三選一改裝卡與技能變體、WebAudio 音樂音效、四個可選角色、成就系統（每個成就永久傷害 +1%，部分解鎖角色）。

## 設計方向

### 1. 隨機性：每次出門都不一樣

- 升級時三選一：每次升級抽出 3 張「卡」，內容是新技能、技能變體或被動效果，像吸血鬼倖存者。
- 技能變體：同一技能有多種「攻擊模式」，例如電池彈會分裂、會彈跳、會留下火場。變體在取得前不顯示全貌，只顯示名稱與一句提示，保持神秘感。
- 裝備詞綴隨機，另有罕見的「異常詞綴」，會改變玩法，不只加數值。
- 地圖詞綴隨機，讓每一輪的挑戰與獎勵不同。

### 2. 上癮循環（短、中、長）

| 週期 | 循環 | 獎勵 |
| --- | --- | --- |
| 數秒 | 擊殺、掉落、傷害數字 | 即時回饋 |
| 數分鐘 | 升級三選一、換裝 | 構築成形 |
| 單輪 | 守關者、地圖完成 | 稀有掉落、成就 |
| 每天 | 離線收益、每日首次出門加成 | 回來有東西領 |
| 長期 | 圖鑑、解鎖角色與道具 | 收集完整度 |

原則：
- 變動獎勵：掉落有稀有度驚喜，但保底機制避免連續空手而歸。
- 差一點：稀有道具掉落時有短暫演出，增加期待。
- 進度永遠可見：下一個目標（下一級、下一個成就）一直顯示在畫面上。
- 不使用損失厭惡的負面手段，例如連續登入懲罰、倒數壓力。

### 3. 掛機與上班族

- 全程可自動戰鬥。操作只集中在「選卡、換裝、搭配技能」這幾個決策點。
- 一次看 1 至 2 分鐘就有完整的收穫與決策，不需要長時間在線。
- 離線收益：保持現有 6 小時上限，並加入「輪次摘要」：升了幾級、得到什麼、發現什麼新東西。
- 手機直式為主，單手操作。
- 通知與推送一律不做強迫式提醒。

### 4. 紓壓但不無腦

- 戰鬥畫面要有爽快感：成群怪物、連鎖、爆炸、數字。
- 腦力放在構築：技能、輔助寶石、裝備詞綴、天賦的搭配，而不是反應速度。
- 難度會懲罰不當搭配，例如抗性或防禦不足，逼玩家調整，但不會讓掛機一直被卡死。
- 提供明確的「為什麼死了」提示，引導玩家調整構築。

### 5. 解鎖與成就（Meta 進度）

- 成就範例：
  - 單輪擊殺一定數量。
  - 用只有某種道具完成地圖。
  - 不使用某類技能打倒守關者。
- 成就解鎖：新角色、新武器外型、新技能變體、新地圖類型。
- 新角色有不同的起始技能與被動，鼓勵嘗試新流派。
- 圖鑑：已發現的裝備、技能、變體、怪物，缺漏處顯示剪影。

### 6. 流派與搭配

- 目標：至少 5 種可辨識的流派，例如火力暴擊、冰凍控場、連鎖閃電、召喚、持續傷害。
- 每個流派由「核心技能＋輔助組合＋關鍵裝備／傳奇＋天賦路線」構成。
- 傳奇裝備改變技能行為，成為構築的核心。
- 數值設計原則：流派之間不求相同強度，但每個流派都有可行的通關路線。

### 7. 耐玩

- 深度地圖（階層）無上限，詞綴疊加提升挑戰。
- 賽季或每週挑戰，限定詞綴與獎勵。
- 轉生機制（後期）：重置進度換取永久加成與新選項。

## 道具與主題

所有裝備、技能、道具使用 Y2K 都市物件，例如耳機、翻蓋手機、BB Call、MD 隨身聽、電子寵物機、摺疊傘、霓虹光管。避免使用受商標保護的名稱（例如數碼寶貝）。

## 建議實作順序

1. 圖鑑：已發現的裝備、技能、變體、怪物，缺漏處顯示剪影。
2. 更多技能變體與傳奇裝備改變技能行為。
3. 角色專屬起始技能。
4. 離線輪次摘要。
5. 構築提示（死亡原因）。
6. 數值平衡：晚期死亡次數偏高，需要調整。
