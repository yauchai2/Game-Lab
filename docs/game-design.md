## 現行遊戲重點（2026-10-28，使用者再次確認）

目標玩家是平時時間不多的上班族。自動戰鬥與離線經驗提供持續成長；回來後用有限時間研究武器、技能、道具與攻擊模式的組合。體驗要紓壓，但決策有影響、值得反覆玩。

核心是隨機性、未知新攻擊模式的發現、流派構築與長期解鎖。參考 **POE2／暗黑破壞神2** 的掉落、詞綴與構築深度，以及 **吸血鬼倖存者** 的自動攻擊、密集清怪與組合變化；具體做法須適配掛機，而非直接複製持續手操或重開即清空全部進度。

「上癮心理學」在本專案落實為：不確定的新發現、短中長目標、收集進度與驗證想法的回饋。玩家想回來，是因為仍有組合想試；不靠錯過即損失、連續登入壓力或假裝差一點中獎。這是本次設計取向，不表示現行遊戲已實作以下全部方案。

### 構築循環與隨機規則（優化提案）

**掛機／離線累積 → 回訪看經驗與掉落 → 發現新模式／組件 → 比較並手動配裝接線 → 短試驗 → 保留有效構築與成就進度 → 再探索。**

- 隨機首先改變「如何攻擊」：分裂、彈跳、穿透、環繞、延遲引爆、召喚等為設計例子；逐一核對既有技能／配件／卡匣支援後再選，不能把例子當已存在的功能。
- 輸出形態、作用範圍、觸發條件等有區別，再搭配數值詞綴。避免大量名稱不同、畫面與決策相同的掉落。
- 發現前保留未知感；鑑定後清楚顯示行為、代價與相容條件，換上前提供短預覽。不要靠模糊規則隱藏負面效果。
- 同一攻擊槽先限定一個主要模式轉換，再讓輔助配件修改投射、範圍或觸發；衝突模式明示互斥，允許的組合列明先後順序。不得讓多個轉換默默互相覆蓋。
- 隨機有探索邊界：保留至少一套能用的基本構築，重複物有既有回收／改機用途；若某模式長期不可得，再按實際掉落資料評估分類保底或定向追求。保底／定向方案未定數值、不當作已上線。
- 自動戰鬥不等於自動替玩家做構築決定：沿用手動配裝、接線、收藏與構築保存，離線結算不偷偷換裝或覆寫配置。

### 忙碌玩家的時間尺度（設計目標，待驗證）

| 可用時間 | 本次回來能完成甚麼 |
| --- | --- |
| 約30秒 | 看懂離線經驗、重要新發現與下一步；可立即離開，不強迫逐件抽獎演出 |
| 約3–5分鐘 | 比較一件關鍵掉落、改一項配置、完成短試驗 |
| 約10–15分鐘 | 研究一組模式相容性、比較兩套流派、挑戰一個有意義的目標 |

離線報告聚焦「成長／新發現／卡住原因」，重複低價值物彙整，不把有限遊玩時間耗在清單。日常回訪不要求搶點登入或強制領獎才能繼續成長；實際上限與結算規則仍由現行owner決定，本次未更改。

### 長期耐玩與角色解鎖（提案）

短期追求一個新模式，中期完成一套可運作流派，長期收集模式／關鍵物與完成特殊成就。每次出發累積某項可見進度，不等於每次都發稀有物或跳成就；避免成就只剩擊殺計數與無限加數字。

可研究「首次完成不同模式組合」「用不同流派達成指定挑戰」等成就，獎勵新物品池、候選模式或未來新角色。保留已解鎖／已建立角色，不將現有四職業突然重新上鎖；新增角色應帶來不同決策與構築方向，不是純數值升級。長期解鎖需保留初期基礎流派的可行性，避免物品池愈大愈難找到必要組件。

### 驗收與角色重製的關係

四主角提供不同的起始循環與傾向，不把武器、元素或攻擊模式鎖死在某個角色。人物輪廓固定可辨，持用裝置與攻擊表現可隨構築變化；稀有裝備不能成為基本職業辨識的必要條件。重製依[角色方案](characters-current.md)同步調整。

後續以實際可用的不同攻擊模式數、短回訪完成率、首次模式試用所需時間、重複物浪費與同階可行流派數驗收；不單用登入次數、在線時長或總DPS判斷成功。先核對現行能力，再驗證兩套同職業、不同模式的構築是否有明顯觀感與取捨，並檢查離線結算、配置還原與新解鎖相容性。

世界觀與故事以[街頭改裝、委託與追逐](story.md)的新提案為入口；舊電台失常主線不再是設計限制，但現行程式尚未替換。

## 大改版方向：永久構築與遠征發現（最新提案）

2026-10-28。使用者已明確允許大改。本節取代早期候選方向；允許重構不代表以下機制已實作、已平衡或已發佈。核心支柱維持不變，既有角色／物品／進度須有可核對的遷移路徑。

### 1. 把四種內容分清楚

| 層級 | 玩家在這裡決定甚麼 | 保存／隨機邊界 |
| --- | --- | --- |
| 角色 | 喜歡的人物、招牌循環與擅長的成長方式 | 永久身份與進度，不用每輪重練 |
| 構築 | 武器基底、攻擊模式、配件、裝備及天賦如何配合 | 手動編輯、保存與還原；離線不擅自改動 |
| 遠征 | 要追求哪類發現，願意承受哪種地圖風險 | 分段自動戰鬥，結算後保留成果；能中途離開 |
| 發現 | 下一個模式、關鍵詞綴或收藏會帶來甚麼新選擇 | 隨機內容有價值差異，已獲得／已結算結果不隨開關畫面重抽 |

現有系統先依這四層重排入口、責任與獎勵，優先刪掉重複工序，不再加一層與接線板／模式卡匣做相同事情的新系統。

### 2. 重新分工武器、模式與角色

**武器決定基本手感；模式改變攻擊行為；配件創造連動；天賦強化取捨；角色提供循環偏好。** 七部位物品與已取得資料先保持；若日後改欄位，必須先提出對等轉換及可還原方案。

一套構築至少應回答：怎樣清小怪、怎樣打首領、怎樣保命。用模式與組件解不同問題，而不是全堆最高傷害。一件裝備最多承擔一個主要行為改變，其他詞綴提供支持；不在武器、卡匣、天賦三處重複塞相同「分裂」。

最新首批均為青少年，定位為男力量戰士、女清冷法術、女敏捷遊俠、男召喚，後續可加角色；世界觀按SANDWICH新參考重構，戰士／法術／遊俠／召喚只作玩法定位；使用者已採用破壞者／駭客／遊擊手／機偶師；職業名與定位已確認，職業技／被動行為已在角色設定補定，數值及接入待驗。循環方向分別為力量釋放、施法場域／連鎖、精準投射、召喚協作，詳見角色設定。清冷不是冰系限制，召喚不自動等於亡靈；不新增需要手操的反應測驗。

### 3. 讓「抽到新玩法」比「又多一件垃圾」更常被感受到

- 首次發現模式時，提供行為預覽、清楚代價，以及可裝入哪套現有構築；發現與試用之間不再強迫多層升級／鑑定／重洗。
- 候選做法是「模式收藏永久記錄，裝備品質繼續追求」：模式的基本試玩權與高品質掉落分開，重複模式可支援升階／定向研究。先用現有零件／重複物資源驗證，不另開貨幣。
- 能追求的掉落家族與稀有驚喜並存。玩家可選「偏投射／偏裝置」等路線權重，但不能直接指定每次掉哪一件；地圖只顯示真實生效的權重差異。
- 沒抽中想要的模式也累積可見研究進度；按分類抽取或定向補齊的候選成本要由實際掉落分布決定，不先承諾固定幾抽必得。
- 收藏池逐步擴大，但必要基礎件有穩定取得途徑；新解鎖不能只稀釋掉落池。已見模式再次掉落可直接辨識，減少重複揭曉動畫。

### 4. 遠征服務掛機，而非要求玩家跟著計時器玩

遠征以數個小段組成，第一樣板可先以約8–12分鐘模擬進度作調校起點，不是要求玩家在線8–12分鐘。隨時離開後沿用原構築繼續；回來先看已完成段落與實際收益。失敗限制後續推進或效率，不撤銷已結算的收藏、成就與整個角色進度。

出發前最多一個主要取捨：穩定收益、偏向某掉落家族，或較高風險的挑戰。過程不加入離線時一定要作答的升級卡；玩家不回來就按已選路線繼續，不默選新技能或強制停在獎勵頁。第一輪不增加局內臨時構築與額外配點，以免長期研究被每輪清零抵消。

離線同樣有經驗與合理發現機會，經由原結算owner依出發構築、路線及能力快照計算，不能憑空宣稱通過未模擬的首領／操作成就。多次讀取同一回訪不重領；結算與領取狀態要原子保存。上限、速度與收益率先不改，後續按基線測試再調。

### 5. 把維護成本降下來，研究深度保留下來

回訪先呈現三件事：成長了甚麼、有甚麼首次發現、目前哪個問題值得處理。只為真正需要選擇的物品打斷玩家；低階重複物按使用者已設定規則彙整，收藏、已鎖定與被構築引用的實體物品保持保護。

試用新模式時，可把當前構築複製到暫時試驗位，比較後由玩家明確套用或放棄。試驗只讀取／借用合法持有物，不複製資源或派發正式戰利品；保存構築仍引用同一物品。接線板仍有研究價值，但不要求每次換同類組件都重拉一整塊板；先改善局部替換與相容性提示，再決定是否簡化板規則。

### 6. 解鎖的獎勵是「多一種可能」，不是永久數值膨脹

成就優先鼓勵新體驗：兩種不同流派完成同階內容、首次完成一組連動、在某項限制下通關。判定真實裝備與戰鬥紀錄，不能只憑選到模式或按預覽就算完成。

新玩家保證可用起點；後續道具／模式／新角色提供橫向選擇。角色解鎖帶新循環，不天然全面優於初始角色。既有玩家已解鎖角色、已持有收藏不重新上鎖。成就加成的既有投入也不直接抹除；如改為解鎖獎勵，先提供遷移對照與前後可用性驗證。

### 7. 可玩樣板（暫停，非當前工作）

使用者最新指示暫時不做可玩樣板；以下保留為後續候選，不執行、不阻塞角色設定與美術。

恢復時的候選範圍為 **1角色、2技能、5個現有模式、1小怪路段及1無小怪首領**。使用CHAIN／BEAM，模式候選為CHAIN_FORK、CHAIN_OVERLOAD、BEAM_SWEEP、BEAM_FOCUS、BEAM_CAPACITOR；定義與效果可核對01-data，實際組合及平衡須再測。

| 樣板構築 | 待驗證差異 |
| --- | --- |
| 分叉紅外線＋掃射雷射 | 多目標覆蓋是否明顯、與單體構築有何代價 |
| 過載紅外線＋聚焦雷射 | 單體／直線命中是否有價值，冷卻與清場損失是否可接受 |
| 紅外線命中蓄電＋撥號放電 | 能否看懂「另一技能供能→雷射消耗電荷」的連動，循環不靠說明書才理解 |

目前先做新角色設定、輪廓、靜態風格預覽與三視圖，不需等待樣板。日後恢復樣板時可借現用模型驗玩法，不把它當新美術方向。樣板的模式／資源可用測試工具明示提供，不偽裝真實掉落率或正式玩家紀錄。

必須驗證：回訪約30秒能說出新收穫；首次得到模式後3–5分鐘內能試出差異；同角色至少兩套構築各有適用場景；離線前後收益及快照一致；試驗／還原不丟物或複製物品。新模式數、試用率、短回訪完成率、重複物浪費與各場景表現一起評估，不單看DPS／登入時長。

通過後才擴大模式池、四角色被動、新人物／裝置、遠征選擇與長期解鎖。若差異看不懂，先修改攻擊行為與回饋；若維護太繁，先刪掉重複操作。不要用更多角色或更稀有掉落遮住基本循環的問題。

### 8. 執行與遷移

本次完成架構提案與現有模式定義核對，尚未實作或執行樣板。工具／素材／文件可在本任務分支製作；src/index/dist依目前協作分工由原型討論串接入，不能將寫了規格說成已經改版。交接時沿用既有戰鬥、掉落、回訪、收藏與存檔owner，不各開一套狀態。

先保留資料快照及舊存檔測試，再逐步替換玩法與資產；不清空玩家投入、不覆蓋其他分支成果。現用角色素材按使用者先前確認暫留，等新人物及遊戲接入驗收後移除。未合併、未發佈。

## 橋底里：世界、裝備與技能的接合規格（2026-10-28）

本節為本輪完成的詳細文字方案，優先於上方抽象候選中的衝突處；不改現用程式、數值或玩家資料。城市制度以[世界設定](world-current.md)為準，具體首區內容與來源表以[第一街區規格](first-district.md)為準；這裡只定系統責任、循環與接入驗收。

### 取得、發現與試用分開

1. **先有可用起點。** 四角各有職業循環，另可搭共享技能。首區使用現有1級FIRE，第一張固定教學模式為FIRE_SPLIT；合法供電／盤面及原技能條件都須成立。CHAIN10級、BEAM16級的研究延後，避免新手得到不能用的教學獎勵。
2. **未知來自取得前。** 普通掉落仍可能帶來未知模式／詞綴；第一張教學首件例外固定，確保玩家真的見過行為改變。新模式取得後可以揭示行為及代價、作無獎勵預覽，再決定是否裝上；不以強制實裝才揭示完整規則製造誤配成本。
3. **預覽不等於持有新物品。** 已取得物可借用到隔離試驗配置；未持有物只能看固定示意，不獲正式傷害、掉落、成就、首通或供電豁免。實裝仍須手動通過原相容檢查。
4. **保存有效想法。** 三套構築記憶仍引用同一實體物品。局部替換優先，缺物／供電不足／模式互斥時說明原因；取消或試驗退出恢復原配置，不能複製UID、回溯消耗或繞過引用保護。

目前MODES註解仍記「裝過才顯示完整效果」，本輪將上面第2項定為接入方向，未改程式；須由原型owner統一介面及鑑定狀態，不能只改文案聲稱已提供預覽。

| 模式卡匣 | 該技能一個主要輸出轉換 | FIRE_SPLIT分裂、FIRE_BLAST周圍引爆 | 同技能不默默疊兩個主要轉換；互斥沿原槽位呈現 |
| 輔助配件／接線板 | 合法供電、位置與效果支援 | 原有配件標籤及電路限制 | 不新增另一個與盤面做相同事情的組裝小遊戲 |
| 裝備詞綴／天賦 | 數值支援、有限預算與取捨 | 原七部位及三套構築 | 不在每層重複加分裂、無限回放或免費供能 |

七部位仍是頭部、身體、手部、飾品、鞋子、武器、副手。角色固定服裝／標誌配件與穿戴顯示的關係之後做映射，不因本輪裝備文案自動改四人剪影、把Mimo當副手或為鞋款加能力。普通／魔法／稀有／暗金與現有回收、校準、升階、核心重構繼續各自職責；首區先露出比較與換用，不一次教完全部打造操作。

### 隨機有三種，獎勵必須可解釋

| 變化 | 本輪決定 | 保存邊界 |
| --- | --- | --- |
| 敵群與路段組合 | 在已定模型／遭遇角色中變化密度與組合，關鍵教學及首通關底固定 | 一次出發沿用已確定內容，不因重開畫面重抽有利首通 |
| 裝備基底／詞綴 | 由現有掉落資料處理，首區不另設一套品質機率 | 已結算物沿用實體與庫存保護，離線不擅自換上 |
| 模式發現 | 首張FIRE_SPLIT固定，其後按已合法開放的家族隨機；重複物仍有用途 | 已有來源及成就發獎須去重；不承諾每輪新模式或捏造保底次數 |

穩定來源承托經驗與基本資源，稀有發現帶新想法；「每次都有所得」不等於「每次都有稀有物」。路線權重在實作前只有設計意圖，未測概率不顯示確切百分比。擴池時按技能合法性及家族分層，避免新模式全塞進第一區、令必要入門件愈來愈難找。

首張教學模式以外，不先確定每次抽取結果；已產生結果亦不隨讀檔重新抽。後續RNG實作需分開戰利品與純視覺隨機來源，此為接入驗收，不聲稱目前完成隔離。

### 忙碌玩家的一次回訪

| 時間目標 | 必要內容 | 可直接離開的位置 |
| --- | --- | --- |
| 約30秒 | 原離線報告顯示經驗／等級變化、首次發現、目前可試或未滿條件的原因 | 看完或略過均已保存收益，不需點逐件領獎 |
| 約3–5分鐘 | 看一件關鍵物、試一個模式差異、明確套用或還原 | 原配置可用，無新決定時仍可沿舊路線繼續 |
| 約10–15分鐘 | 比較兩種合法組合，調整普通回收／模式追求方向 | 配置與路線保存，不要求完成整串對話才有效 |

例示回報（不是實測數字）：「經驗與零件已保存；新發現：引爆電池；可配：灼熱電池；目前路線：空台回收。」若取得BEAM卡匣但未到16級，直接顯示條件，不誘導空按升級，也不自動代裝。重要發現與既有未讀owner銜接，不新增多套紅點記錄。

離線沿用catchUp→update／offlineBulk→pickup／保存→uxOfflineReport。現用catchUp只精確模擬前600秒，後段依既有收益模型處理，上限讀offCapSec；不能以「離線完整玩完新街區」描述外推。現用storyAdvance在G.offline時直接返回，新主線不能偷偷利用掉落數量補發首領通關或替玩家作交貨決定。

首階段採保守方案：普通收益繼續，故事首通待在線正式事件確認；回來可讀已達成且可核對的發現，但不能宣稱離線推進新章。若日後要離線故事進度，必須先另定事件帳本／一次性發獎與遷移規格並驗證，不能僅靠文案改成已支援。

### 失敗與耐玩

失敗提供「單體不足／清場慢／生存不足」等有戰鬥證據的提示，不能僅憑總DPS猜原因；暫時無足夠資料就只報實際受擊與失敗結果。玩家可回普通路線累積、換模式或調配件，不收新維修稅、不清空已結算物。每個角色至少保留可完成普通內容的基本配置。

長期次序是單一模式差異→兩種合法組合→供能／消耗連動→同階限制挑戰→下一區新家族。成就獎勵以渠道、收藏選項及未來新人物為主，不將既有四角重新上鎖、不抹除舊成就投入。渠道解鎖仍須技能／圖紙／盤面相容，不是技能門檻豁免。

## 裝備與技能第二輪：四人不同，構築仍可跨用

FIRE_BLAST和FIRE_SPLIT同屬FIRE主要轉換，不能在同一技能槽疊成一張免費超級模式。BEAM_FOCUS與BEAM_CAPACITOR亦是同槽替代，不是上下兩層同時套用。四人都可借別人的研究方向，但需相應武器／技能／供電及投入；上表是偏好，不是獨佔配方或已證明的最強流派。

### 四類可用詞綴取向

保留七部位及原合法詞綴池，這裡只給選裝思路。物品實際可出哪些詞綴以01-data的POOL與既有部位路由為準，不為故事道具開免費新屬性。

| 選裝思路 | 可研究的原有詞綴 | 玩家面對的選擇 |
| --- | --- | --- |
| 穩住再玩 | 生命、護甲、回復、抗性 | 攻擊慢一點但較少失敗；不能把生存詞綴一律當垃圾 |
| 出手順啲 | 原有攻速／冷卻相關效果 | 縮短空窗與提高單擊之間取捨；按實際技能冷卻計，不只看面板總分 |
| 打中重點 | 傷害、會心、對精英等合法詞綴 | 集中單體／精英用途，可能犧牲一般路段效率 |
| 擴大接觸 | 原有範圍或投射支援，由相容配件提供 | 要犧牲配件位置、供電或傷害，不在普通護甲偷偷加一個新主要轉換 |

「鬆身工作外套」可先映射現有身體基底，使用生命／護甲／回復等合法詞綴；它不附送供電或職業重擊。四件代表武器先做原物品基底到新造型的明確對照，未確認前不配新ID、不批量改名舊玩家物品。

### 六個支援配件的研究問題

| 原有ID／名稱 | 值得試的問題 | 必須檢查的限制 |
| --- | --- | --- |
| FOCUS／鎖頻晶片 | 單次傷害與會心增加後，更長冷卻是否令清路反而慢？ | 效果按原文與冷卻owner；不保證所有技能受益相同 |
| FORK／分線器 | 一個小額鄰近命中是否足以處理散怪？何時可以省下一個覆蓋技能？ | 與模式分叉分開來源，不能讓分線命中再次無限分線 |
| RECOVER／備用電池 | 穩定命中回復能否讓同階失敗減少，值得放棄多少輸出？ | 回復間隔與全局回復額度仍有效，不能每一回放都另開額度 |
| DELAY／延遲緩衝 | 延後回放能否補輸出空窗？敵人已離開命中區時有何損失？ | 沿用原回放判定、事件與上限，不能拿回放再當新的原始施放 |
| ANCHOR／定錨電容 | 少次重擊是否有利於該場景，而非只讓傷害數字更大？ | 傷害與冷卻代價同時生效，不加第二個無限蓄力條 |
| SPREAD／廣域接頭 | 範圍／射線變寬後，能否減少漏怪，抵銷單體強度代價？ | 只用在現有相容的範圍／投射技能；依盤面標籤檢查，不憑角色職業放行 |

以上只核對定義存在，尚未做四角盤面求解、效果疊加或離線收益比較。先各驗一個配件，之後才混搭；若觀感不清楚，先改善回饋，不以更多卡匣掩蓋差異。

### 發現之後的三個下一步

第一次見到的物件先讓玩家知道：「改變哪個行為」「可否現在用」「如果未用得到，欠甚麼」。已持有模式不再強制逐次播放未知揭曉；保留探索來源與收藏進度，未發現的完整池不一口氣曝光。沒有手動套用就保留原構築。

- 想輕鬆：沿普通回收繼續，稍後才比較，不因略過新物件停工。
- 想試新花樣：從原構築複製一份隔離試驗配置，先觀察模式，再加一件相容配件；試驗不發正式獎勵。
- 想追一件：查看已核對的來源／定向取得途徑；沿用原零件、電路點及回收用途，不另加研究票或每天重置的追求次數。

當前BEAM_CAPACITOR已有指定合成入口，本輪延續它，不能為製造未知感而移除玩家已有的確定途徑。實際來源在[接入對照](remake-integration.md)維護；展示模式發現不等於改變持有數量或移走盤面中的卡匣。
