v0.73.0 自動更新、技能特效與手機畫質。

- 自動更新：每次開啟遊戲先核對版本，有新版就自動重新載入。舊版本需先手動重新整理一次，之後就會自動更新。
- 技能特效大幅加強：符文法陣、聚能光點、技能光柱、命中爆發與衝擊環、火焰冰刺電光、凍結冰花、護盾光罩。
- 手機版戰鬥畫面解像度提高。
- 設定：倒下表現新增「無」並成為預設；移除設定頁的混沌重鑄。
- 模式：原地刷怪的經驗與金幣增加 30%。
- 故事：新增終章「夏日最後的傍晚」與五段「夜間頻道」終局故事（深度 45、55、70、85、100 的首領後解鎖），收錄在電台手記，不會彈窗打斷掛機。
- 暫時移除：戰鬥畫面的黑圈（視野遮罩）與設定內的視野範圍選項，鏡頭範圍還原。
- 精簡畫面：隱藏設定頁與技能頁的重複說明文字，接線板只留必要資訊。
- 電腦版面板：較矮的電腦視窗會自動縮小面板內容，標題列與操作入門卡精簡，接線板縮小，重要內容不必再捲動才看到。
- 新增抗性：裝備可帶火焰、冰霜、閃電抗性（上限 75%）；深度 4 起部分魔物帶元素攻擊，按對應抗性減傷，護甲只發揮一半效果。
