v0.69.0 技能線長度加成、視野設定與效能優化。

- 技能盤：連線加成改為按線長計算，線超過 6 格後每多一格技能傷害 +3%，上限 2.5 倍；配件上限維持 3 個，與配件無關。接線頁顯示傷害倍率。
- 視野：設定新增「視野範圍」（近／標準／遠），標準視野比舊版寬約 25%；大地圖跟隨鏡頭時，畫面邊緣會稍微變暗。
- 觀戰：新增快捷鍵 W。
- 音樂：戰鬥畫面收起時，音效停止、音樂變細聲。
- 自轉：Logo、角色與裝扮預覽轉得更快。
- 斷訊裂隙：怪物沿圈邊緣持續湧出。
- 效能：畫面解析度會依實測幀率自動調整，並限制清晰模式的總像素，減少卡頓。
