# Build Lab 對應 Idle Hero：移植建議

日期：2026-10-22。Build Lab 只是用來試玩法機制的 Demo，不是正式遊戲。這份文件說明哪些機制值得搬進 Idle Hero、怎麼對應現有系統、哪些只留在 Demo。遊戲程式碼由原型討論串負責，這裡只給設計。

Demo：skill-assembly-demos/buildlab.html（試玩連結見專案記憶）。

## 一、值得搬進 Idle Hero 的機制

| Demo 機制 | 在 Idle Hero 的對應 | 備註 |
| --- | --- | --- |
| 接線板：從電源拖線，經過配件接到技能 | 取代或擴充現有配件拼圖，面板上拖一條線連起「電源、配件、主動機件」 | 線可以繞路，繞路能多經過配件，也可以避開壞軌。這是它最有趣的地方 |
| 輔助寶石 | 輔助配件：天線、電池、掛飾、貼紙、記憶卡、充電線 | 直接用 Y2K 物件命名，不要出現「寶石」 |
| 同款相鄰 ×1.2 | 同名配件貼在一起加成 | 只留這一條，不做冰火互削 |
| 3 合 1 升階 | 配件合成，沿用現有改機的灰燼與保險絲 | 與零件灰燼共用資源，不另開貨幣 |
| 超頻賭一把 | 現有的超頻晶片 | 50% 升階、35% 沒變、15% 燒毀 |
| 壞軌、熱點、增幅 | 面板地形：壞軌（不能用）、熱點（配件 ×1.4）、增幅（線經過加傷害） | 棋盤固定，所有玩家一樣，不會自己變，避免破壞玩家的構築 |
| 每日詞綴 | 每日加成，Lv6 之後才出現 | 只影響當天數值，不動構築 |
| 技能串聯 | 一個主動機件觸發另一個 | 用下拉選單設定，不需要連線 |
| 傳說掉落與保底 | 與模式卡匣、暗金保底共用同一套保底計數 | 不要另做一套 |
| 構築槽與自動切換 | 現有的 3 組構築一鍵切換，加「遇到某種敵人自動換」 | |
| 自動配置 | 給新手與懶人：一鍵給中庸結果，可復原 | 永遠不給最佳解 |
| 逐步解鎖 | 等級帶動功能：Lv1 只有接線和寶石，之後才加合成、地形、串聯 | 新手任務鏈可直接沿用這個節奏 |

## 二、只屬於 Demo，不要搬

- 「波數即等級」：Idle Hero 有自己的經驗與成長，不要改。
- 重抽背包、直接過關：測試按鈕。正式遊戲取得配件只靠掉落、合成和超頻，否則稀有感會消失。
- Demo 的敵人與數值：只用來比較機制，不代表正式平衡。

## 三、與掛機規則對齊

- 角色倒下後不重新開始：滿血復活，在同一關重整再打，進度、配件、面板都保留。畫面只顯示一行提示（哪種怪漏太多、建議帶什麼），不彈視窗。
- 獎勵不打斷：掉落的配件選擇放在背包頁的待領取區，玩家想看才看，離線期間也不阻擋。
- 離線：只給經驗與一般掉落。傳說配件與鑑定進度必須在線才有。
- 接線是一次性的構築動作，不是每場戰鬥都要操作。上班族幾分鐘內調完，之後放著掛機。

## 四、複雜度控管

Demo 試過後已經拿掉的東西，正式版也不要加回來：配件詞綴、線序衰減、發熱上限、冰火互削、推薦與重抽按鈕、擺放與接線的模式切換。原則是玩家同時要理解的規則最多四條：選主動機件、擺配件、接線、合成。

## 建議刪減與簡化

加新東西之前，先看哪些可以拿掉。Demo 已經先做了前四項。

| 項目 | 處理 | 理由 |
| --- | --- | --- |
| 每日詞綴 | 已刪 | 每天變數會干擾玩家辛苦排好的構築，也加重理解負擔 |
| 依敵人類型自動換構築 | 已刪 | 一鍵切換已夠用，自動切換是第二套規則 |
| 第三張棋盤 | 已刪，只留兩張 | 兩張已足夠示範棋盤變化 |
| 熱點與增幅兩種地形 | 已合併為一種「強化格」 | 一種就能表達「擺在這裡更強」 |
| 隱藏組合 | 建議從 8 組減到 5 組 | 找得到才有驚喜，太多反而沒人記得 |
| 技能分頁 | 建議只顯示有接線的技能 | 技能多時列表太長 |
| 傳說掉落 | 建議保留兩種技能、兩種配件即可 | 目前各有 4 與 2，圖鑑填寫負擔偏重 |
| 配件階級 | 維持三階，不再加 | 合成與超頻已構成成長線 |

## 五、待決定

- 主動機件是否能放在面板任意位置。Demo 只能在右側一列互換位置，若要任意位置，要連帶重新設計壞軌與路徑公平性。
- 復活是否要輕微代價，例如該關掉落減少。
- 接線板與現有拼圖並存，還是完全取代。建議先並存一個版本，看玩家選哪個。
- 手機真機的拖線手感還沒驗證。
