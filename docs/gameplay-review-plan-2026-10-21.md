# 玩法與機制審查計劃

日期：2026-10-21。內部設計文件。依 Alan 最新十項玩法重點制定。

**目標是讓時間有限的玩家，每次回來都有一個值得試的新想法，短時間能完成一次決策，離線期間仍有可信的成長。** 耐玩性以不同打法、可理解的取捨及可達成的探索目標評估。

本輪完成目標整理、程式盤點及有限基線快查，尚未完成長期平衡、掉落分布、真實玩家體驗或留存研究；下列改法及數值是待評估方案，沒有寫入遊戲。

## 2．把十項重點轉為審查問題

| Alan 的重點 | 要驗證的問題 | 合格方向 |
| --- | --- | --- |
| 隨機性 | 抽到不同東西是否改變下一步決策？壞運氣會卡多久？ | 抽取有差異，也有方向選擇與進度保底 |
| 遊戲上癮心理學 | 玩家期待的是什麼？能否從試錯中學會搭配？ | 驚喜、能力感、收藏與完成感形成回訪動機，玩家可以放心停止 |
| 上班族掛機 | 兩分鐘、五分鐘及完整工作日後，能否處理收穫？ | 自動戰鬥，重要決策集中，沒有長串待辦及反覆清包 |
| POE2、暗黑 2、Roguelike 的機制演化 | 哪些交互作用適合自動戰鬥？單局怎樣改變打法？ | 借用構築核心、掉落追求及局內取捨，與永久進度清楚分層 |
| 未知攻擊模式 | 新模式是否有肉眼可見的新行為？是否值得重試？ | 提示可猜方向，實際試用後看見變化與代價 |
| 每次遊玩、成就及解鎖 | 一次回訪是否有可完成的小目標？ | 成果不只加數值，也打開角色、模式或新搭配 |
| 眾多搭配與流派 | 是否存在多種有效打法，還是只剩最高紙面 DPS？ | 角色、技能、配件、傳奇及天賦共同形成不同優缺點 |
| 離線回來有經驗 | 離線進度是否準確、可預期，會否丟失選擇權？ | 經驗與收穫可靠；關鍵發現可留待回來試用 |
| 紓壓但不無腦 | 不操作時是否順暢？決策時是否有因果？ | 操作少、決策有分量；失敗知道可以改什麼 |
| 耐玩 | 第七、十四天是否仍有不同問題可研究？ | 新組合及橫向內容持續出現，重複掉落仍能推進目標 |

心理學在此是待驗證的設計假設，不能僅憑「變動獎勵」推論玩家會喜歡。觀察期待、試用、學會及再次選擇；不以延長在線時間單獨判定成功。

## 3．已盤點的現況

在 Chromium 的全新隔離存檔以 static fixture 讀取定義：9 個主動技能、19 種卡匣、8 種輔助、9 件傳奇、12 件遺物、14 種改裝卡、4 個角色、12 項成就、15 項目標、10 個任務、40 個天賦節點、9 種地圖詞綴、6 種地區。八個技能各兩種模式，閃打三種。

已有六欄拼圖，按等級 1／4／9／15／22／30 開放六列；三套配置保存拼圖與天賦，裝備共用。四個角色已有被動及實際執行的專屬招式；「角色專屬起始技能」仍須另查，不把兩者混為一談。

目前普通推進、地圖與無限塔提供不同長度的戰鬥目標；升級改裝卡、遺物及收藏主要永久累積。這有成長基礎，但不等同於已有完整 Roguelike 單局循環。

## 5．建議的核心循環與機制分工

```mermaid
flowchart LR
    A[離線累積成長] --> B[回來看摘要與新發現]
    B --> C[選一個想試的方向]
    C --> D[保存原配置並快速試用]
    D --> E[自動冒險或短遠征]
    E --> F[驗證搭配與完成小目標]
    F --> G[收藏解鎖與新可能性]
    G --> C
    F --> A
```

四層分工：戰鬥自動執行；構築由玩家決定；短遠征提供這一局的變化；永久收藏與解鎖提供長期追求。普通掛機可以隨時離開，短遠征是可選內容，不能成為每次領取離線經驗的前置工作。

### 5.1．驚喜必須落在攻擊行為

先按「形狀、節奏、目標、連動、代價」檢查現有 19 種模式，逐一記錄可觀察的變化。例如磁鐵聚怪後坍縮、雷射由窄線變掃射、閃打由連拍變收割。每項都要有適用場景及至少一個限制，避免全部變成原版的免費上位。

首次發現前給方向提示及必要限制；首次試用提供簡短的安全觀察機會，完成後留下圖鑑記錄。稀有度、強度、是否新發現分開標示，不能只讓玩家期待更大的倍率。具體鑑定時間待試玩，暫不採舊草案的固定一分鐘／一百殺門檻。

隨機需要方向盤：可選探索技能家族，池中保留跨流派驚喜；重複卡匣能換取定向發現進度。先模擬未出新內容的長尾，再設計保底，不先拍一個保底次數。保底按對應池及「新發現」清楚記錄，不能被無關普通掉落重置。

### 5.2．流派要改變解題方式

先用現有內容建立候選測試表，而非立刻擴增幾十件道具：

| 候選打法 | 要看的差異 | 可能代價 |
| --- | --- | --- |
| 火焰擴散／分裂 | 清群、燃燒與目標轉移 | 單體或起手效率 |
| 冷凍控制／碎裂 | 生存、控制覆蓋與後續傷害 | 不可控場敵人或首領效率 |
| 閃電連鎖／過載 | 密集怪連跳與高單次命中 | 分散目標及慢節奏 |
| 磁鐵聚怪＋範圍打擊 | 位移與技能協作 | 聚怪後的承傷風險 |
| 低生命觸發／冷卻連動 | 裝備核心改變決策 | 安全邊界及掛機穩定性 |
| 閃打／收割 | 近身移動、擊殺連鎖 | 面對高血單體及危險區 |

以上是實測候選，不是已驗證六套同樣強。第一批先驗證三套明顯不同的可行打法，再擴到至少五套；召喚等未實作類別另列候選，不用既有內容數量冒充。

每套需列角色、主動、模式、輔助、核心傳奇、天賦、成形門檻、替代件及克制情境。稀有核心應提升或轉化打法，基本打法在缺核心時也可運作。

### 5.3．永久成長與單局變化分層

研究 POE2／暗黑 2 的物品追求、互相作用及有代價的選擇；研究 Roguelike 的當局選擇如何讓熟悉內容重新組合。審查重點是這些原理能否服務掛機玩家，不照搬操作強度、海量詞綴或強制重開。

候選短遠征沿用永久擁有的角色／構築，另抽臨時規則或有限選擇；結束後保留收藏／發現，臨時效果只留在該局。進入前交代哪些會保留、哪些會結束；中途離開的結算先定義。初期先做一種可重玩的短遠征，不先做賽季、排行榜、轉生三套系統。

### 5.4．上班族的三種回訪

| 情境 | 建議體驗 | 要避免的負擔 |
| --- | --- | --- |
| 約兩分鐘 | 看收益、知道一件新事、選一個方向，能直接離開 | 十幾個逐級彈窗、每件裝備手動比較 |
| 約五分鐘 | 換一個模式、試一次短戰鬥、看差異、保留或還原 | 為一次試用重排整板或消耗唯一核心 |
| 較長的自選遊玩 | 研究多套構築、打有特殊規則的遠征 | 只有把怪物生命放大的耐力賽 |

離線上限比較現行六小時與十二／二十四小時候選；評估八至十小時工作、八小時睡眠及一整天沒開的情境。這些時數是測試選項，沒有批准或實作為新數值。離線的基本成長應支持主要遊戲目標，主動遊玩的優勢集中在可選的研究、取捨與體驗。

| 階段 | 審查工作 | 交付物與完成門檻 |

先完成 A、B 的正式報告，再鎖定第一批玩法改動。C、D 的研究可先建立清單，但新增模式不得遮掩結算及掛機問題。這是工作順序，沒有用未量測的工時承諾完成日。

## 7．測量及驗收設計

### 情境與可重現性

保留原有存檔；使用隔離存檔與固定亂數來源的實驗工具，後者尚待建立。記錄來源提交／工作區指紋、配裝、技能盤、角色、敵人及持續時間。挑新手、成形期、缺核心、後期各情境；一次只改一個變項。

隨機分布先用多個種子小批量測試，遇到大變異及尾端問題才擴大樣本。固定種子只用於比較，不能據單一種子下平衡結論。報告中位數、P90／P95 及失敗比例，說明時間窗與樣本數；尚無真實玩家資料時，不填虛構留存率。

戰鬥分單體、多怪、分散怪、承傷壓力四類；同等資源下看完成率、實際時間、生存、觸發次數及傷害來源。先檢查訓練場有無包含角色專屬效果、冷卻／動作競爭，再與實戰交叉核對。

### 判斷是否進步

| 目標 | 主要指標 | 驗收方式 |
| --- | --- | --- |
| 回來值得打開 | 回來後第一次有意義決策所需時間、未處理選擇數 | 兩分鐘情境可完成摘要及一次決策；不因離開前未開自動而被默默消耗重要選擇 |
| 未知但不亂抽 | 可用新模式、重複、未出新內容的長尾 | 分開統計「看見」「能裝」「有試用」「改變打法」，保底邊界可重現 |
| 深度與自主 | 被主動試用的模式／構築數、嘗試後保留或還原原因 | 核心裝備不被無預警拆除；玩家能比較、保存及還原 |
| 多流派 | 各情境完成率、實際耗時、死亡率、核心取得成本 | 至少三套初期打法各有用途，不要求各項傷害數字完全相等 |
| 離線可信 | 實際經驗／各資源、截斷、死亡、選擇及結算次數 | 0／20／60 秒邊界、6 小時上限與 8／12／24 小時回來對帳；重載不重複領 |
| 每次有成果 | 一次遊玩得到的發現、解鎖、目標進度 | 沒出稀有品仍能推進一個可理解的目標，不需要每次送稀有品 |
| 長期仍想研究 | 七／十四天內容消耗、剩餘組合與目標 | 區分模擬預測及真人反饋；不以單純在線更久當成功 |

「有意義決策」需改變至少一項：打法、風險承擔、目標掉落、解鎖方向或自動化規則。無效點擊及逐個領獎不算。

心理體驗另以短試玩訪談核對：「你現在想試什麼？」「為什麼留下這件？」「今天可以在哪裡安心停？」答案會比只看點擊次數更能判斷探索感及上班族負擔。暫無實際受試者，不宣稱這部分已完成。

## 8．第一批候選改動及暫緩項目

**建議先行批次：** 修正結算計數 → 定義離線重要選擇 → 保護構築核心及試用還原 → 讓一個新模式從掉落、試用到發現形成完整循環。這批先沿用現有素材與內容驗證。

後續才決定重複卡匣回收／定向池、臨時規則遠征、玩法型成就及新模式擴充。所有新物件維持 Y2K 街頭數位物件語言，特效需能辨識連動且不遮住角色與 HUD。
