## 接入契約

- 來源：原GLB／Blend與設計圖分開保存，不覆寫M01。包內附來源說明、manifest／hash、前右後實際渲染與遊戲近景／正常鏡頭。
- 朝向：Y-up、正面+Z、地面原點，模型以局部尺寸交付；遊戲holder scale只由src整合持有。先讓第一隻與AKI／M01同場比較，不照搬M01的8.5倍。
- reader：目前`g1-monster.js`支援節點TRS、剛性分件、頂點色、索引與節點動畫，不支援skinning／morph／貼圖或完整PBR。使用唯一節點名稱、TRIANGLES、緊密bufferView、LINEAR／STEP；不要輸出node.matrix或CUBICSPLINE後被靜默忽略。若原件需要新能力，先與Claude協調reader擴充，不刪原件資料硬塞。
- 動畫：交付Idle／Move／Hurt三段。需Claude明確映射既有Hop／Hit名稱；M01本身仍保留Idle／Hop／Hurt，不重新命名原GLB。Idle／Move循環，受擊淡入淡出；根節點XZ不含導航位移。動作與遊戲衝刺／跳躍／鑽地／閉殼的外層位移只保留一個擁有者。
- 材質：先以頂點色unlit與M01比較；受光版另做同場A/B。mesh按活動分件配置，預算實測後確定。共用幾何／材質不可被單隻受擊／死亡改壞；依賴逐隻opacity的材質須有正確所有權。
- 穩定資料：保留type key、AI、血量／傷害、碰撞、掉落、boss用途、SAVE_KEY與玩家進度。只替換表面，不把視覺尺寸當碰撞尺寸。

[contract.json](contract.json)列出四類現有姿態的實測尺寸；數據來自已完成的2e3da0a審查，而非新GLB的測量。它只供前後比較，不是固定新模型規格或碰撞盒。尤其寬足蜘蛛應保留低輪廓；不能把四隻都縮成M01相同高度。
