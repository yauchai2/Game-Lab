# 全介面像素掌機：0.27.1

Alan 要求把文字、生命／經驗及操作介面也延伸為低解析度 Y2K 日系數位感，取代 0.26.2 只對 3D 場景下採樣的範圍。本版保留銀灰掌機外殼與藍紫液晶，沒有改動存檔或玩法數值。

## 實作

- `tools/pack_font.py` 保留 Cubic 11 原字模，新增供 16px 正文與輸入使用的 LCD 光學字模。1600 units/em，輪廓、字寬及基線對齊 100 units，每格對應 1 CSS px；標題／主要讀數使用原字模 24px，輔助標籤使用原字模 12px。字體均為常規 400，不合成粗體。沿用原 OFL 授權。
- `UX_THEME` 擁有字體 token，`UX_MATERIAL_CSS` 擁有所有工作頁、HUD、提示、確認及兩種編年史的字級和像素材質。減少細線圓角，銀色／藍紫表面改為分段色帶、2px 亮暗邊與硬陰影；彈窗移除背景模糊，保留遮罩。
- 血條與經驗改成分格外觀，視覺比例向上取至 2% 步幅；精確生命數字、ARIA 值與遊戲計算不取整。質感關閉時恢復連續血條與平滑基底材質，字體不重排。
- 原生文字及輸入維持語意、可搜尋／選取、觸控及 IME；不以圖片代替可操作文字。獨立編年史帶入兩份字模及同源材質。

3D 仍是真正低解析度 framebuffer＋最近鄰放大；UI 使用預先生成字模及原生硬邊 CSS，**並非將整份 DOM 縮進低解析度 Render Texture**。瀏覽器縮放、分數座標、未收錄自訂名字及系統下拉選單仍受原生繪字影響，不宣稱每種裝置都沒有反鋸齒。這個選擇保留輸入與無障礙，也不增加每幀 DOM 截圖、文字畫布覆層或全頁 SVG 濾鏡。

新增字模增加下載成本：單檔由 1,350,589 增至 1,445,782 bytes；以本機 gzip 計算由 406,933 增至 475,403 bytes，並非 GitHub 實際傳輸量。沒有實測手機幀率提升；真機卡頓與長時間字體辨識仍需驗收。

## 驗證

- `tools/test_font_grid.py`：直接解析產物內 WOFF2，1255 個 LCD 字形、字寬與基線對齊格線，字符映射與原字體一致。
- `tools/test_lcd_browser.cjs`：390 × 844、DPR 3 與 1440 × 900、DPR 1；字體載入、字級、無橫向溢出、371／1000 的精確生命對應 38% 視覺取格、滑桿位置不變、原生輸入草稿、無彈窗背景模糊及觀戰返回。
- 既有瀏覽器回歸：UX 12 項、布局 10 項、觀戰 10 項、全局質感 8 項、圖示 7 項／86 格，以及倉庫、掉落保存、天賦、減少動態與特效池檢查，全部通過。
- 字體／穩定 DOM／離線補算檢查通過；UX 邏輯與渲染尺寸策略通過。靜態 strict audit 與 DESIGN lint 均無錯誤或警告。

以上為雲端 Chromium 驗證，並非 iPhone Safari 或完整報讀器驗收。最終移除模糊後重跑 LCD 跨尺寸檢查。
