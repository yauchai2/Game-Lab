本版新增本機排行榜，並把角色頁小手機改成等距低解像度 3D。

- 新增「排行榜」（更多 → 排行榜）：自動記下最深層數與無限之塔最高層，連同當時的完整構築。
- 可隨時記錄目前構築，點開能看到技能與配件接線、裝備詞綴、遺物與天賦點數。
- 構築可複製成構築碼傳給朋友，貼上就能觀摩對方怎麼砌。
- 榜單預設放了幾筆標示「示範」的假排名，只用來看版面。
- 角色頁小手機改成等距視角的低解像度 3D 模型，慢速自轉。
- 目前排行榜只存在這台瀏覽器，全球榜之後開放。
