# 參考遊戲研究與借鏡

研究日期：2026-10-20。

2026-10-21 更新：Alan 已提供 16 張實際介面參考。本輪逐張檢視並實測官網新手／桌機／390 寬流程，詳細見 [介面結構研究](auto-wanderer-ui-study-2026-10-21.md) 及 [Idle Hero 版面規格](idle-hero-layout-design-2026-10-21.md)。以下保留舊版玩法文字研究；其數值、推論及建議不自動成為目前遊戲規則或本輪實作要求。

## 資料來源與限制

- 參考遊戲的官網是單頁 web 遊戲，網頁本身內建完整的遊戲內說明（FAQ、各系統說明、任務清單），本文數字與規則大多來自這些說明文字。
- 搜尋不到 Steam 頁面，也找不到第三方評論或攻略。它是免費、免登入、免安裝的 web 遊戲（桌面與手機皆可），所以「玩家評價」沒有資料，下面只談設計本身。
- 部分機率數值在程式內是變數，這裡只寫文字說明確定的部分。

## 一句話定位

像素風放置刷寶構築遊戲：角色自動戰鬥，玩家負責配裝、煉金與拼技能寶石。明顯是 POE 的放置版，語言很像「放置版流放之路」，跟我們想做的方向非常接近。

## 核心循環

1. 角色在地圖自動打怪，掉裝備、符文石、材料、石板。
2. 玩家整理背包（拾取篩選、保留規則自動分解成「符文灰燼」）。
3. 用灰燼與材料做煉金：萃取、灌注、磨礪、鑲嵌、腐化。
4. 在「技能拼圖」格子裡擺寶石，調整流派。
5. DPS 夠了就打 Boss 解鎖下一張地圖，最後進入終局：守護者、終焉之主、無限之塔、無限君主、賽季 Boss。

重點：玩家的操作量集中在「整理與決策」，戰鬥本身完全不用管。這正好符合「時間不多的上班族」。

## 系統拆解

### 1. 隨機性與抽取機制（沒有抽卡，全部是掉落＋加工）

- 沒有 gacha。所有隨機都來自擊殺掉落，所以「掛機等於抽卡」。
- 裝備稀有度：普通、魔法、稀有、傳奇、神話，詞綴數 0、1、2、3 至 4、7。
- 77 種隨機詞綴，有階級（T0 到 T4，T1 可被腐化提升成 T0）。
- 45 件獨特裝備，另有神話獨特，機率約為每件掉落物的極小比例，只有 83 級以上怪物會掉，離線不會掉，也不會被自動分解（避免玩家誤刪）。
- 菁英怪必掉裝備；石板的「危險度」可提高稀有度與掉落量（風險換報酬）。
- 神器保底：賽季神器前 N 次固定機率，之後每次未掉落機率遞增（有壞運氣保護）。
- 掉落資源本身分層：灌注石 Lv4 只由 83 級以上一般怪以 1/30000 掉落、離線與菁英與 Boss 都不掉，製造「值得掛機等的聖杯」。

### 2. 煉金（掉落之後的第二層隨機）

- 萃取：消耗萃取石把裝備的一條詞綴拆成符文石，裝備消失（Lv1 有失敗率，Lv2 起 100%，Lv3 起可取獨特效果，Lv4 可能升一階）。
- 灌注：把符文石隨機替換裝備上一條詞綴（所以有賭博感）。
- 磨礪：重洗詞綴數值；封印石可鎖住想保留的詞綴。
- 鑲嵌：插槽裝備（Lv75 以上才掉）放入符文石，詞綴固定。
- 腐化：一顆石頭，結果隨機（升階、數值浮動、沒變化、變差），之後不能再煉金。典型「賭一把」。
- 奇蹟石：讓裝備進入「奇蹟狀態」，下一次煉金必定正向，用過一次即失效。
- 保護石：避免萃取時摧毀裝備。
- 材料可以用灰燼合成，4 顆同級升 1 級，並有自動合成開關。
- 設計精華：煉金把「爛裝備」變成「素材」，所以任何掉落都不是垃圾，玩家永遠有東西可做。

### 3. 成長與解鎖

- 等級每 3 級開放 1 格技能拼圖。
- 轉職試煉在 30、45、60、75 級，選分支，每場給 2 點天賦點，天賦逐排解鎖；重置天賦要花灰燼（有成本但不高）。
- 新手任務鏈分步解鎖系統：到 15 級才開放「煉金」，任務會引導玩家做第一次萃取等。每個任務給資源獎勵。
- 地圖線性：打倒 Boss 解鎖下一張；Boss 需先擊殺一定數量怪、限時 90 秒。
- 後期層層解鎖：石板（77 級後）、守護者（印記，限時挑戰，失敗不退還）、終焉之主（三種碎片）、無限之塔（打倒終焉之主後開放）、無限君主（集滿無限印記）、賽季地圖（90 級）。
- 最多 5 個角色，灰燼、材料、卡牌進度、神器全帳號共用，倉庫共用。
- 怪物卡牌：每張地圖累計擊殺 N 隻解鎖三階加成，2 萬隻變閃卡並解鎖拖尾特效，純粹靠時間累積的收集目標。
- 構築 1 至 3：一鍵切換整套技能拼圖、裝備、天賦、神器，免費。

### 4. 流派搭配

- 3 職業（劍士近戰高血、弓手遠程高暴擊、法師遠程範圍），49 種技能寶石。
- 技能拼圖是俄羅斯方塊式格子：主動寶石自動施放，輔助寶石只強化「上下左右相鄰」且標籤相符的主動寶石。
- 寶石形狀不同，變異寶石還能改形狀與格數，合成後形狀重新隨機。
- 同名寶石可放多顆；額外施放、暴擊觸發、元素（燃燒、冰緩、感電）、中毒層數、流血、召喚物等都有獨立的乘算規則。
- 穿梭寶石：其他職業的輔助寶石可連結本職業的主動寶石，玩家會想跨職業試組合。
- 訓練場有假人：量測 DPS、各技能傷害佔比，讓搭配有明確回饋。
- 排行榜（無限之塔層數）可查看他人的「構築快照」，這是很強的攻略內容與社群動力。

### 5. 離線收益

- 關閉頁面或手機切到背景才算離線；電腦切分頁不算，戰鬥照常。
- 每次最多 8 小時。
- 經驗為線上的 75%，掉落次數為線上的 25%。
- 神話獨特、怪物卡牌進度、神器經驗離線都不累積，避免離線取代在線。
- 未使用的角色只累積經驗，沒有掉落，切回該角色時領取。
- 離開不到 60 秒回來會快轉補上，不算離線。
- 設計精華：離線只給「成長」不給「驚喜」，最稀有的東西必須人在場才掉，讓玩家有理由回來看畫面。

### 6. 成癮與留存設計

- 稀有層級＋聖杯：神話獨特、灌注石 Lv4 的低機率，配合「石板危險度」調高機率。
- 賭博式加工：腐化、灌注、鑲嵌都有隨機成功或變差，並有保護石、封印石、奇蹟石給玩家控制感。
- 明確的下一步：每次登入都有「可以升級的材料」「差幾隻怪就能挑 Boss」「碎片差幾個」。
- 資源互相卡位：奇蹟石只由無限君主掉、腐化與洗鍊石只在無限之塔掉、神之碎片只在賽季圖掉，迫使玩家在不同玩法間輪流。
- 賽季「眾神之怒」：90 級開放，三位神的碎片、神之化身、賽季獨特裝備、金色「神眷詞綴」，賽季結束後地圖關閉但裝備保留；全服 Raid 血條與每日貢獻點（需登入雲端存檔），台灣時間 0 點重置，里程碑給外觀，貢獻點可在商店換物。
- 自動化開關齊全：自動挑戰 Boss（生命達設定值才開打）、自動進塔、拾取篩選、批次分解、批次萃取、自動合成。這些省掉重複操作，「紓壓但不無腦」的關鍵就是自動化是玩家設定的規則，而不是完全沒決策。
- 雲端存檔綁 Google，每 5 分鐘上傳，一次只能一台裝置玩。
- 沒有廣告，免費，主要靠口碑與排行榜。

## 對照我們的核心設計重點

| 我們的重點 | 參考遊戲的做法 | 我們可借鏡 |
| --- | --- | --- |
| 隨機性 | 掉落＋煉金雙層隨機，保底與保護機制並存 | 雙層隨機：怪物掉「Y2K 零件」，再加工 |
| 成癮心理 | 聖杯掉落、賭一把的加工、材料互相卡位 | 小機率大驚喜＋保底；加工要有「保護」道具 |
| 掛機／上班族 | 8 小時離線、自動化規則、整理才是玩法 | 離線只給成長，稀有驚喜留給在線 |
| 不知道抽到什麼新攻擊 | 寶石形狀與標籤決定流派，變異寶石改形狀 | 新技能的「模式」應改變玩法，不只是數值 |
| 每次遊玩有成就、解鎖角色與道具 | 任務鏈引導、卡牌、里程碑、稱號與外觀 | 做成短回合的成就＋永久解鎖 |
| 流派搭配 | 俄羅斯方塊式技能拼圖，相鄰加成，標籤對應 | 這是最值得抄的核心 |
| 離線回來有經驗 | 離線 75% 經驗、25% 掉落 | 直接採用類似比例 |
| 紓壓但不無腦 | 玩家設規則（篩選、保留、構築） | 規則型決策取代操作型決策 |
| 耐玩 | 賽季、無限之塔、排行榜、Raid | 先做無限塔，再考慮賽季 |

## 具體建議（依優先序）

1. **把「技能拼圖」改造成 Y2K 版本**：在固定格子裡放「主動道具」（例如摺機發射訊號、耳機音波、數碼寶貝召喚）與「輔助配件」（例如電池、天線、掛飾），輔助只強化相鄰的主動道具，標籤相符才生效（範圍、投射物、元素）。這樣搭配性、新鮮感、深度都有，而且很適合手機畫面。
2. **雙層隨機**：怪物掉落「機種」或「零件」，再用「改機」系統加工（對應萃取、灌注、磨礪）。建議做成幾種道具：
   - 拆解：把裝備拆成一條詞綴零件（保留低成本失敗率）。
   - 改裝：把零件隨機替換到另一件裝備。
   - 重新校準：重洗數值，可鎖定一條詞綴。
   - 這樣任何垃圾掉落都有用處，也能解決背包爆滿。
3. **離線收益沿用同一原則**：8 小時上限，經驗約七成半，掉落約兩成半，最稀有的掉落與收集進度必須在線才有。這能保護「回來看」的動力。
4. **自動化規則做成系統而非設定**：拾取篩選、保留規則、自動挑戰 Boss（生命低於某值不開打）、批次拆解。這是上班族體驗的核心，要在早期就有。
5. **用任務鏈做新手引導並逐步解鎖系統**：例如 15 級才開放改機、30 級轉職。避免第一次進遊戲就被所有系統淹沒。
6. **保底與保護**：稀有掉落用「未掉落則機率遞增」，改機失敗有保護道具，玩家才不會挫折。
7. **終局單一無盡玩法**：無限之塔（每層更強、層數排行榜、每 10 層加一條規則）。實作簡單，耐玩度和社群話題都高。排行榜可附帶構築快照，讓玩家互相偷學。
8. **訓練場／假人**：測 DPS 對流派玩家非常重要，成本低。
9. **角色與帳號共享**：多角色共用材料與倉庫，對應我們「解鎖更多角色與道具」。
10. **短期不要做**：賽季、全服 Raid、雲端存檔綁 Google。這些需要後端與營運，等核心玩法站穩再說。

## 不建議照抄的地方

- 它的資訊密度極高（77 詞綴、多種石頭、倉庫、批次規則），對休閒玩家門檻偏高。我們的 Y2K 風格要更直覺，材料種類先砍到 3 至 4 種。
- 它的美術是像素風，我們是 Y2K low poly 3D，戰鬥畫面要承載「刷一大堆怪」的爽感（吸血鬼倖存者式），這點跟它自動走位的小畫面不同，要另外設計。
- 它的離線只算「關閉頁面」，對 web 版有意義；我們若包成 Steam 版，要重新定義離線觸發。
- 它的商業模式尚不明（無廣告無內購），我們若想上 Steam，要另外評估。
