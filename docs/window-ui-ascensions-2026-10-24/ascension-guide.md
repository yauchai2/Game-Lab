## 接地鐵衛

- 厚殼接地：護甲+15。
- → 接地堡壘：護盾上限由9%提高至12%；職業專技傷害再降低5%。

- 備用電容：最大生命+4%。
- → 長效電容：普攻護盾持續時間由2秒提高至4秒。

- 導體鍍層：每秒回復+0.3。
- → 帶電接觸：跳電傷害倍率提高0.6，但第一擊倍率降低0.3。


## 電弧破陣

- 分歧接點：閃電傷害+6%。
- → 串聯中繼：專技額外跳向2個目標；每次專技傷害再降低5%。

- 長距天線：技能急速+4%。
- → 延伸導線：跳電搜尋半徑由30提高至42，第一擊仍需近身。

- 集中電荷：增加傷害+4%。
- → 電弧尖峰：跳電倍率提高0.8，最多跳電目標減少2。


## 超載鬥士

- → 重錘脈衝：專技第一擊倍率提高1.5，跳電倍率降低0.4。

- 絕緣握柄：護甲+15。
- → 過載穩壓：普攻護盾上限提高2個百分點，每秒回復+0.4。


## 回聲奏者

## 靜域調音師
