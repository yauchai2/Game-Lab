v0.58.0 街區樣板。

- 城市綠洲地圖改成一條橫貫的街道：柏油路面、中線、斑馬線、人行道與路緣，兩側是連續的店面。
- 店面有遮陽棚、招牌、玻璃櫥窗與冷氣機，街邊擺放販賣機、盆栽與貨箱。
- 島後方多了一道高架橋，人行道變寬。
- 店面分成六種：雜貨、小吃、服飾、電器、咖啡麵包與藥局洗衣，各有遮陽棚、像素招牌圖案與櫥窗擺設。
- 設定新增「倒下表現」：紅色液體或訊號碎片（彩色方塊飛散後淡去）。
- 阿街的角色與兩件裝備（修補耳機、改裝電棍）換上新的配色層次；部分店面掛上原創像素招牌。
- 戰鬥範圍與路線不變。設定裡新增「街區地圖」，可切換街區樣板與原版地形。
