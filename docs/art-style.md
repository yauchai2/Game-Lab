> **共用生圖提示詞（2026-10-28）：** Alan 認可的 [手作早期日系遊戲素材模板](handmade-japanese-asset-prompt.md) 已完整保存正向／負向原文，供後續替換 `[SUBJECT]` 重用。本次為風格偏好記錄，未改動現有角色、模型或比例。

> **歷史美術文件，非現行驗收規格（2026-10-26 更正）。** 本文保留原版本的粉彩、數位寵物、笑臉、史萊姆／骷髏與紫色王冠等演進紀錄；衝突內容已被 [Ice Cream 創作基準](creative-direction.md) 取代。怪物／同伴一律以 [現行十二款與同伴設定](monster-catalog.md) 為準，不按本文重新生成或替換模型。

Idle Hero 的主風格是 **Y2K low poly 3D**：千禧年前後的遊戲與網路美學，低面數切面造型，柔和粉彩，藍天白雲，角色是大頭大眼的「數位寵物」比例。

先前的 Colorfigures 手繪墨線風格已經退為次要參考，遊戲畫面不再使用粗墨線或手繪抖動。

## 1. 視覺語言

- **低面數切面**：所有造型都由少量多邊形組成（二十面體、七到八邊的圓柱、圓錐），平塗上色，讓每個切面清楚可見，不做平滑法線。
- **柔和粉彩**：大面積用高明度、低彩度的顏色，點綴色才飽和（粉紅、青、鵝黃、薰衣草紫）。
- **無墨線**：不描輪廓。形狀靠切面明暗與色差分開。血條和傷害數字等介面元素用極細的深藍紫（`#2b2552`）。
- **等距固定視角**：正交相機，從右前上方看下去，視角不旋轉，保留掛機遊戲一眼看完戰場的清晰度。
- **藍天白雲背景**：天空藍漸層，像素風白雲，遠處有淡藍的城市剪影；不用暖色紙紋。

## 2. 色彩原則

| 用途 | 顏色 |
| --- | --- |
| 天空 | `#8fcdf7` → `#c9e9ff` → `#f5fbff` |
| 深色（文字、極細線） | `#2b2552` |
| 地面（森林） | `#b8e6a8` / `#97d28c` / `#6aa27a` |
| 地面（沙漠） | `#ffe4a8` / `#f2cb86` / `#c9a064` |
| 地面（雪原） | `#eef7ff` / `#cfe3f6` / `#9ab4d6` |
| 地面（熔岩） | `#c9aebc` / `#a98ea0` / `#7a6078` |
| 點綴 | 粉 `#ff9bd0`、青 `#8fe3f0`、黃 `#ffd35a`、紫 `#c3b0ff` |

- 地面三階色分別是頂面、側面、陰面，由亮到暗。
- 每個生態只有一組主色，怪物與裝飾的色相跟著生態走。
- 稀有度顏色（普通、魔法、稀有、暗金）只出現在掉落物與介面，不染到場景。

## 3. 造型哲學

- **數位寵物比例**：頭約佔身高的三分之一，眼睛大，四肢短，輪廓一眼可辨。
- **眼睛**：貼在頭部表面的動畫眼睛（白底、漸層虹膜、深色瞳孔、兩個高光），因為是真正的 3D 物件，不會長到頭的背面。
- **主角**：雙馬尾、耳機、寬鬆工作褲、厚底鞋。裝備會改變外觀：護甲等級決定衣服顏色與肩甲，高階護甲換成頭盔與角，武器長度與顏色隨稀有度。
- **怪物**：史萊姆是果凍球；骷髏是大頭小身體；巨獸圓胖，有角與獠牙；首領更大，戴王冠，換紫色。
- **裝飾**：每個生態有自己的道具（森林：松樹、灌木、蘑菇。沙漠：仙人掌、岩石、牛頭骨。雪原：雪松、水晶、雪人。熔岩：尖刺、岩石、噴口）。

## 4. 光影

- 一盞半球光（天空藍 + 薰衣草紫）加一盞暖色平行光，配上平塗切面，得到三階左右的明暗。
- 影子是腳下一片柔和的藍紫色橢圓，不做即時陰影圖，保持畫面乾淨。
- 受傷時整個模型閃白，冰凍時閃冰藍。

## 5. 互動與動態

- 一切動作都有誇張的擠壓與回彈：史萊姆壓扁，骷髏彈跳，巨獸揮棒。
- 技能特效用發光的平塗球體與環，不用粒子雲：火球、爆炸、新星、閃電、隕石。
- 掉落物會彈跳、旋轉、發光柱；稀有以上有光柱。

## 6. 介面

- 泡泡視窗：白到淡藍漸層，白色內框，粉彩外框與柔和投影；標題是緞帶，稀有度決定緞帶與外框顏色。
- 血條、經驗條是圓角膠囊，用粉紅與綠。
- 中文介面文字用全形標點；英文標點後加一個空格。

## 7. 技術做法

- 渲染使用 three.js（`src/vendor/three.min.js`，MIT 授權），正交相機，`MeshLambertMaterial` + `flatShading`。
- 遊戲邏輯（`src/game/01` 到 `03`）與渲染分開，渲染只讀 `G` 狀態。
- 血條與傷害數字用 SVG，座標由同一台相機投影而來。
- 建置：`python3 tools/build.py`，輸出單一檔案 `dist/idle-hero.html`。

## 參考：幸福 Online（Strugarden）

只作風格分析，不使用任何遊戲素材。能查到的公開資料（[維基百科](https://zh.wikipedia.org/zh/%E5%B9%B8%E7%A6%8FOnline)、[巴哈姆特資料庫](https://acg.gamer.com.tw/acgDetail.php?s=7563)）只描述了整體方向，介面細節沒有文字記載，所以介面部分是依「可愛 Q 版日系 MMORPG」的一般語彙推演。

- **Q 版 3D 可愛風格**：大頭小身體，男女各有數種基本模型，髮型、表情、膚色、髮色、服色可自由搭配，服裝組合很豐富。
- **浪漫中世紀歐洲童話**：溫馨可愛的氛圍，世界有海港城市、古代魔法遺跡、雪地要塞、浮空大陸與彩虹。
- **戰場是分格的地形**：我們的掛機戰場同樣是一塊分明的方形地塊。
- **介面（推演）**：圓潤的泡泡視窗、糖果色按鈕、緞帶標題、膠囊血條，整體柔和不尖銳。

融合方式：場景與角色維持 Y2K low poly，介面改成泡泡視窗。卡片是白到淡藍漸層、白色內框、粉彩外框；標題是依稀有度上色的緞帶；按鈕是有高光與按下回彈的糖果按鈕；血條與經驗條是帶高光的膠囊；字體用圓體。

## 檢查清單

- [ ] 沒有粗墨線，也沒有手繪抖動。
- [ ] 每個造型的切面看得見，顏色是粉彩。
- [ ] 眼睛、耳朵等特徵位置合理，從任何角度都不會長錯面。
- [ ] 背景是藍天白雲，不是暖色紙。
- [ ] 四個生態有各自的主色與道具。
- [ ] 新增的怪物與裝飾遵守同一組比例與色彩。
