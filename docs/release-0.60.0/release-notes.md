v0.60.0 街區角落與雜物精怪。

- 魔物改成街頭雜物精怪：插頭跳豆、紙箱人、啤酒箱牛、塑膠袋飛靈、氣球炸彈、井蓋地鼠、手推車獸、延長線水母等，圖鑑與戰鬥記錄同步改名。
- 數值、行為與預警都不變；紙箱人、塑膠袋飛靈與氣球炸彈已換成簡化臉的新造型，電線團蛛、音箱、小靈、便當盒蟹、地鼠、路燈與射手都加上簡化臉，其餘造型會陸續更換。
- 地區改名成街區的各個角落：綠蔭公園、午後空地、白雪山路、夜市燒烤攤、霓虹商圈、車站貨運場、電台頂樓、海邊堤防、山路電塔、商場地下街、夜晚天橋、停業商場、河邊鐵工廠、港口碼頭、屋頂天線群、郊外採石場、頂樓冷氣區、雨天地下道。
- 無限之塔的三個主題改為停業遊樂場、冷藏倉庫與地下配電室；地圖、存檔與掉落不受影響。
- 水邊、山路、雪地、工業區等地形也會零星出現護欄、電線桿、盆栽、貨箱、冷氣機與販賣機，不再只有街區地圖才有生活感。
- 戰鬥飄字還原為原本的描邊字，取消貼紙氣泡。
