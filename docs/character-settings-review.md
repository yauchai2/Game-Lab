## 已核對、未認定為問題

- 四個legacy key與模型映射一致；`frost`不是強制冰系、`volt`不是強制雷系。保留它們是存檔相容需要。
- 每職業3條昇華，共12條；職業固定與玩家自訂名字可同時成立。四款造型不代表帳號只能建四個角色。
- 回聲奏者文字為本體降低20%、回放35%。程式無天賦時本體係數0.8、回放0.28，`0.28 / 0.8 = 0.35`，不能僅因看到0.28就誤報為回放28%。
- 六章故事的首領名稱是劇情稱呼，與十二模型ID是不同層級；第1／4章共用M04符合catalog，不需要新增第十三款模型。
- 玩家像素五官與怪物／故事同伴無笑臉要求適用對象不同，並不互相矛盾。
- 多個配角參與同一維修／送貨／聲音主題合理；沒有證據將小禾等NPC併為同職業玩家人物，也不自行指定親屬或師徒關係。
