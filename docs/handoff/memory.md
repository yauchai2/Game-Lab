## 專案
- 專案：類暗黑2／流放之路2 的掛機 RPG，Web 版開發。
- 玩法方向：像吸血鬼倖存者、肉鴿、暗黑2、POE2，刷一大堆怪，提升裝備與技能。裝備、技能、道具用 Y2K 都市物件：耳機、摺機／手提電話、數碼產品等。
- 遊戲核心設計重點：隨機性；成癮心理學；掛機，目標是時間不多的上班族；POE2／D2／Roguelike 機制；玩家不知道會抽到什麼新攻擊模式；成就解鎖角色與道具；多種武器技能道具搭配流派；離線回來有經驗；紓壓但不無腦；耐玩。目前重心是玩法機制。
- 參考遊戲（僅內部）：自走勇者 Auto Wanderer；研究文件 idle-hero-docs/auto-wanderer-research.md。方塊拼圖不是硬性要求，可用自己的點子。已做：拼圖、模式卡匣、成就／目標、遺物、元素反應、圖鑑、暗金保底、改機、離線規則、無限之塔、角色頁與裝扮。
- 進行中／待辦：新手任務鏈、訓練假人、構築一鍵切換；人物身體比例與怪物模型再優化；手機版（下方面板、拖曳、音效）需真機驗證；暗金掉落率與各系統平衡未量化。
- 手機版版面：上面是戰鬥畫面、下面是面板（只參考 layout，不參考其風格）。
- 美術主風格：Y2K low poly 3D（低面數切面、柔和粉彩、天藍白雲背景、寬褲厚底鞋、耳機、街景高架橋），並參考「幸福 Online」，UI 為作業系統視窗風。要酷感，不要幼兒式可愛；頭大身小可以。保持浮島造型，鏡頭不要太遠，邊緣要淡出不要硬裁。角色臉部特徵依朝向合理。three.js 平塗低面數 3D，角色與武器、圖示用 Blender 建模。像素字體 Cubic 11。
- Repo：yauchai2/Game-Lab，draft PR #1（遊戲本體）；PR #2 試玩連結打包腳本；PR #3 已合併。文件在 idle-hero-docs/。
- 試玩連結：私人 Artifact https://claude.ai/artifact/HufzcEfT1TWJBi6D5pQQRb ，更新時沿用同網址發佈新版本；連結為知道連結者可開，要限制需 Alan 自己在 Share 調整。
- 之後可能上 Steam：先維持 web，最後再用 Electron／Tauri 打包；GPT Image 生成素材的商用條款上架前要確認。
