## 3. 破壞者

**選角短介紹：**「近身拆開局面，蓄起力量再一次放出去。」

### 人物與外形

在工房幫忙搬料、拆廢件、仍需向熟手請教的少年，靠敢拆、懂借力和熟悉工具逐漸被叫作破壞者。他想先有自己的工作角落，長遠開一間能決定替誰做事的工房。不接明知會把仍住在裡面的人一併清走的拆卸單；缺點是太快把問題理解成「拆開就行」，忽略人情和條款。

**整體形體：** 方鈍短上身、寬鬆直筒工裝褲；裡面是自然的少年身形，手腳及關節有清楚體積。外套的寬來自鬆量，肩線下落，側面胸背有自然厚度。膝肘鬆，稍歪頭，把重量放一邊；力量感來自借力與工具，空手看仍是街頭少年。

**頭與臉：** 黑褐頭髮改方短平頂，兩側簡短、後腦收平，只有前額一撮向上折起的厚髮角；頂線以幾段方折為主，側面露出耳位。短柔臉、簡化耳塊、橫闊卡通大眼、平直粗眉，上眼皮略低、左右開合微差；小鼻、小嘴略偏，隨性中有好奇。頭部正面安靜，3/4讀到太陽穴、臉頰與下巴幾個大轉面。

**表情基準：** 日常底表情是眼皮稍低、單眉微抬、嘴線偏平，像對安排有點不服但仍在聽；成功才短暫露一邊嘴角，遇麻煩先皺眉而非一直笑。

**服裝體積：** 磚珊瑚寬短運動外套敞開，暖粉筆白寬T下襬稍露；左右袖同長、同高推至肘下，袖管有厚度，左腕海松綠寬帶貼合腕部，外側只有一塊暖白扁方扣，止於手腕、不伸向指節。墨藍寬鬆直筒工裝長褲從髖到褲腳大致同寬，膝位只留一兩個大折線；左大腿外側一個扁平側袋，前後其餘部位保持乾淨。褲腳離地、只稍蓋暖粉筆白方頭板鞋的鞋面，鞋頭、鞋側及墨藍鞋底可見；輪廓方直而鬆。背面外套保持大色面，配件收斂。

**配件與生活姿態：** 方扣護腕是主要配件焦點，像自己換過扣的舊運動護腕：海松綠寬帶配暖白扁方扣，方扣朝左腕外側，不遮手背、不夾住手指；雙手維持自然放鬆的稍大掌形。短柄工具收右腰，掛點避開手與褲管。等人會坐低、倚欄杆或歪頭看告示，準備動手才收重心。他撿回字體好看的舊告示牌，卻不按牌上時間開工；口氣直接，遇到不懂的接點會向熟手請教。

### 裝置、能力與成長

起始代表武器定為**短柄衝擊工具**：厚鈍工具頭、清楚握柄，右手主握、左手可扶；與左腕護腕分離，空手亦有角色辨識。工具不是稀有專裝或職業唯一可用武器。近身力量感由踏步借力、轉髖、揮動慣性與短促衝擊回饋呈現；工具仍是可操作的短柄尺寸，休息時整個人輕巧隨性。此為既有重擊的視覺演出，不新增傷害、助力系統或戰鬥規則。

- **自動職業技「拆場」**：短蓄力後向面前釋放一次重擊與擴散衝擊，清楚區分近處重擊及外圍覆蓋。首領不因畫面擊退效果被永久控制。
- **被動「硬接」**：有效承壓或連續命中形成一次蓄勢，強化下一次職業重擊；提供命中累積途徑，不能要求刻意挨打才有完整玩法。蓄勢有上限，消耗後重新累積。
- **昇華三向**：拆台（集中破防）／震場（擴散震波）／硬骨（承壓反擊）。集中換取範圍，擴散換取單體效率，承壓路線增加防護但降低爆發頻率。
- **聲音與語氣**：短句、偏低但仍是少年聲，無刻意壓成成年低吼；命中是短鈍撞擊，蓄勢只一次簡短提示。
- **語氣例句**：「門可以拆。住喺度嗰啲人，你安排咗未？」

## 4. 駭客 Hacker

**選角短介紹：**「改寫輸出，讓放電與場域接成另一套規則。」

### 人物與外形

從拆自己的舊設備開始自學核心改裝，現時替熟人做小規模排查，遇到陌生故障仍會查資料、試錯，喜歡交換私製模式。她想做出不會被原廠遠端收回使用權的工具；不替客戶藏暗門。缺點是太相信自己的預判，計劃變了卻忘記告訴別人，出錯後先修系統才學著解釋與求助。

**整體形體：** 窄而短的上身、完整斜髮殼與耳機弧線，向下接高腰微喇叭長褲。無袖上衣旁露出自然比例的手臂，手只稍大；稍收下巴、肩鬆、手肘離軀幹一點，保留臂身空隙。清冷是專注與省力的態度，會好奇、出錯與小得意。

**頭與臉：** 霧藍紫主髮殼包住後腦，前方一塊厚楔形斜瀏海、一側長束及少量外翹尾，正側背連成同一髮型；不靠紙片薄髮或密集尖刺。偏心唱片耳機以暖粉筆白為主：左耳罩是帶一處缺角的厚圓盤、中央一小塊酸檸黃，右耳罩是較薄的墨藍方匣；頭帶保持有厚度的低邊數弧，與髮束間留空。短臉、小下巴、簡化耳位與偏長的大眼底形，半瞇上眼皮、斜視及短嘴線表達注意力；抬眼時大眼輪廓清楚，側面仍有臉頰／後腦深度。

**服裝體積：** 灰橄欖無袖crop-top，圓領、正常肩帶寬度、直身鬆量，前方一個暖粉筆白圓形色塊；領口、袖窿與下襬有簡單厚度，前後下襬同高。暖粉筆白高腰微喇叭長褲在髖、大腿保留活動鬆量，膝上輪廓較俐落，膝下才稍微放闊；以少數完整前側面交代外張方向，沒有工裝側袋或堆積皺褶。褲腳離地、只稍蓋海松綠厚底便鞋的鞋面，鞋頭、鞋側與墨藍鞋底可見。高腰線自然、全身舒展，耳機、髮尾與肩線分開。

**配件與生活姿態：** 偏心唱片耳機為主要生活配件，左圓右方的形狀在側面也可辨認；她等人時會轉一下左耳罩外圈。左腕薄厚適中的核心介面與右半掌手套收斂，不讓腕介面遮住整段手臂；介面小酸檸黃面平時不發光。稍大的長掌以短手勢操作，休息時手臂放鬆、視線仍會被新裝置吸引。她收集沒甚麼用途但設計很認真的小程式；不急著解釋所有事，成功時嘴角才微動。

### 裝置、能力與成長

起始代表武器定為**短棒形導能器**，像經私改的測量工具；左腕調校、右手定向。雙手武器時介面仍在腕上，自動施放不要求一直點螢幕。她透過自己設備釋出的能量造成實際作用，非電子敵人亦能受影響。

## 5. 遊擊手

### 人物與外形

從替熟悉的街坊跑腿、記捷徑開始，逐步接觸追蹤與投送；熟的是自己走過的路，跨區仍會迷路、問人或重新記路。她想有自己的路線、朋友與約定，不必每次照安排走；不出售居民的藏身處與私人通道。缺點是答應得太快，為維持「搞得掂」的形象，把小麻煩接成大麻煩。
