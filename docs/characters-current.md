# 角色設定與重製方向

2026-10-28 · Asia/Taipei。唯一角色文字入口，不附圖片。使用者已明確指定四種角色：男性力量戰士、清冷女性法術角色、敏捷女性遊俠、男性召喚角色，之後會增加角色。這些定位取代上一版造型brief；現用遊戲、素材與存檔尚未改動。

## 已確認的方向

- 角色定位參考POE2的清晰原型與構築深度，世界觀按新上傳SANDWICH影片方向重構為街頭改裝與委託冒險（具體設定為提案）；不直接搬用POE2的人物、背景或裝備。
- 首批四人性別與主題如下；確切姓名、年齡、配色、服裝、能力與昇華尚待定。
- 隨機攻擊模式、武器／技能／道具組合、掛機與離線經驗仍是核心。職業提供特色與擅長方向；跨流派需合理的裝備與構築投資，不能四人玩起來完全相同，也不一刀切封死其他技能。
- 先文字設計；暫不生成圖片、三視圖、模型或可玩樣板。現用角色素材、內嵌資源及必要建置來源留至新角色驗收替換，不作新設計限制。

### 戰士：力量有重量，但屬於這條街

身形結實、肩背寬，站姿穩，輪廓以方形和低重心為主。服裝由耐用工作衣、護腕、厚鞋與可拆式防護件出發，不套中世紀重甲。表情直接，動作簡單、有停頓和份量。

職業想像是用身體與工具打開局面。可探索重擊、震波、蓄能反擊等分支；武器仍能帶出不同攻擊模式，不預設每套構築都依賴受傷觸發。性格與私人故事另寫，不直接沿用已刪的修理員提案。

### 法術角色：清冷的獨立施法者

新世界觀已不受電台主線限制。「術師」或「調律師」均為待定名稱；樂師可以是背景／分支，不必為保留聲音主題而硬套職業。女性、清冷、法術定位保持，施法方式依新故事的改裝核心／異常能量方向再設計。

她能辨識異常頻率，利用聲場、共振與電磁設備把訊號轉成可見的攻擊與控制。這是世界觀內的施法表現提案，並非已確認的新超自然法則；不必新增神祇、魔法學院或異世界。樂師的聆聽、節奏與編排仍能形成個人特色，但不要求她每次施法都演奏。

清冷透過平靜目光、克制表情、直立姿態和精確手勢呈現，不等於只用冰法。服裝可結合俐落長線條、短外層與有空隙的袖形，讓施法手勢清楚；不靠尖帽／長法袍或大型耳機證明身份。

戰鬥要看得出「施放→作用區域／效果→連動」：可探索音波共振、電磁連鎖、干擾場域等方向。日後若加入寒冷技能，也只是構築選項。不能只做拿音盤射擊的外形換皮，亦不把她預設為替隊友加成的輔助吟遊詩人；她必須能獨立清怪、打首領與掛機。

若保留「樂師」作正式職業名，也應搭配「法術／共振」副標題與真正的施法表現；代價是第一眼容易被誤認為純音樂或輔助角色。名稱需隨新世界觀重新評估，不因上一輪建議而定稿。

### 遊俠：敏捷與投射，不變成普通速遞員換裝

身形輕巧，四肢動作俐落，輪廓以斜線、短外層和不遮手腳的裝備為主。身份可來自街區巡線與速遞，但戰鬥優先呈現追蹤、瞄準、多角度投射與快速換位的感受。

武器方向可研究改裝發射器、投射工具或弓形裝置；具體形式待文字方案確定。範圍清場、精準單體、異常／機動是可探索方向，不能只靠擊殺觸發，令無小怪首領戰失去整個職業循環。「敏捷」不等於要求玩家不停手操閃避。

### 機偶師：男性召喚者，與召喚物形成構築

人物站姿較收斂，以控制、觀察與部署動作區別於戰士的直接力量。服裝由設備改裝工作者出發，控制器與模組留在易讀的位置；避免所有職業都以寬褲、大耳機作同一模板。

核心不是多帶一隻裝飾寵物，而是能研究少量重型機偶、多個小型機偶、支援／輸出配比。這些都是未實作的候選；先確保基本召喚不靠稀有掉落才成立，並讓人物自身動作與召喚物貢獻看得懂。召喚物不計入玩家角色數；故事收音機同伴另沿用[怪物與同伴設定](monster-catalog.md)，不混成同一系統。

## 之後新增角色的原則

首批四人只是起點，不固定為永遠四職業／十二昇華。新角色至少帶來一個不同的構築決策或資源循環，亦須有獨立輪廓與街區身份，不能只換性別、顏色或給更高傷害。未來角色主題與性別尚未決定。

模式、裝備與技能按行為／相容性設計，避免每新增角色就複製整套物品；職業資料與解鎖條件應可擴充。保留已建立角色和已取得收藏，將來接入前先定遷移對照，不直接把舊樂師存檔轉成新女性角色或覆蓋玩家選擇。

## 世界觀、故事與製作邊界

- 故事依[新世界觀提案](story.md)重寫，不再沿用修好電台的主線；四種角色各自都能完成故事，不要求四人同隊。具體背景與NPC關係另提案，不預設親屬、師徒或戀愛關係。
- 法術表現與訊號／設備如何連接須在新能力brief寫清，不因「法術系」自動把世界改成中世紀黑暗奇幻；召喚也不自動等於亡靈。
