## 背景與招牌能力

- **AKI**：每天巡街修電，替小店接試音延長線，今天遇上會逃走的拖板。「短路連打」近距重擊後連鎖跳電；普攻累積短暫護盾。
- **MILO**：唱片店常客，能聽出走調廣播中的重複節拍，希望街上各自的聲音回來。「低頻環流」向周圍釋放音波；持續普攻累積節拍、加快專技。
- **PING**：熟記店家、班車與送貨路線，用摺機追查錯送的訊息，出發前先回覆鄰居。「訊號連射」按距離選取多個敵人；普攻討伐後增幅下一輪連射。
- **NULL**：修理舊寵機、替修理攤試零件，希望每台設備都有歸處。「寵機出動」定期增幅自動寵機；寵機攻擊累積修復，受共用回復額度限制。

## 重製優化計劃（2026-10-28，設計提案）

使用者已要求開始重製，當前步驟為遊戲設計規劃。以下是新設計提案，不是已確認的新人物設定或已完成的素材。本文件維持純文字、唯一角色設定入口；現行資料與提案分開，避免把未採用方向寫進遊戲。

### 1. 目標與範圍

四主角先完成；再處理具名配角、職業寵機與故事收音機同伴，最後補齊無名值班員等配角。十二敵人沿用monster-catalog，不因本次人物重製增加或改名；如需統一材質，另沿用原ID核對。

目標是玩家在選角時能理解四種玩法，在遠距戰場辨認自己，在回城／待機時感受到人物個性。設計必須同時適用單人掛機及四人選角合照，不能只在放大人像時成立。

### 2. 四主角文字造型brief（第一輪提案）

使用者最新要求先文字描述，暫不生成圖片。以下是全新造型與性格提案，尚未定稿；不沿用舊人物圖片。四人均為有日常工作的青年，保留簡陋手作的早期日系3D氣質，霧面大色塊、小型像素五官與輕微不對稱。每人約三個主要色塊，衣服無密集圖案、裝飾文字或寫實磨損。

**AKI｜把問題扛上身的街區修理員。** 輪廓低而穩，上半身偏方，寬短袖與厚實鞋底形成重量；頭部不刻意放大。深棕短髮，一側隨手塞到耳後；眉毛略低，嘴角平直，像正在想「先斷哪條線」。穿褪色磚橘短身工作襯衫、灰白內搭、深石墨直筒工作褲，鞋頭方鈍，褲腳只輕微堆疊，不再四人都穿巨型寬褲。袖口左右折得不同，肘部與腰側留出清楚空隙。主色磚橘／石墨灰，少量奶白；不以電光藍覆滿全身。腰側一個方形電池模組作招牌裝置，可替換，並非固定武器。平時站得穩、手不自覺檢查接點；嘴硬但會默默替店家修好東西，弱點是不肯承認需要幫忙。普通裝備也應看得出踏實身形；新武器可改變手持姿勢，不改成另一個人。

**MILO｜替街區留下聲音的唱片店常客。** 四人中較高而直，肩線放鬆、衣襬有一點外張，輪廓以長線和一個圓形裝置組成。柔軟黑色捲短髮，暖棕膚色；一邊眼皮稍低，笑容很小，像先聽完才回應。穿奶白寬袖外衫、墨綠內搭、收斂的深色微喇褲及扁厚鞋；留白比AKI多，避免整人都是深色。腰前一枚厚圓形播放模組，只有一個大按鍵與一個純色色塊，不畫唱片溝槽或螢幕小字。站姿微偏側，一隻腳輕點拍子，肩膀沒有誇張搖擺。他記得店家喜歡的聲音，擅長讓別人放鬆，卻習慣把自己的心事放到最後。音波感來自動作和節奏，不依賴大型耳機或滿身音符。

**PING｜熟路但不肯敷衍送達的速遞員。** 身形修長偏窄，短外套、斜背帶和略前傾的重心形成斜線；腿部乾淨俐落，腳底仍有一點厚度。栗色極短髮，戴一頂帽簷短而向側偏的淺色工作帽；單邊眉毛稍挑，眼神專注，嘴角有一點自信。穿淡鼠尾草綠短風衣背心、奶白上衣、炭灰收腳長褲，少量橘色集中在包扣與鞋後跟。斜背包貼近背腰，不做巨型包裹；正面只留一條清楚背帶。手腕一個可翻開的方形通訊模組，作可替換設備，不預設所有攻擊都由它發射。待機像隨時會確認下一個路口，但不持續跑跳。行事爽快，最初認為快就是好，逐漸願意為了確認收件人多走一段路。「速度」先表達俐落動作，不承諾尚未實作的移速或遠程普攻。

**NULL｜替舊設備找用途的改裝者。** 圓鬆上半身配較窄的下半身，短而寬的外套輪廓與小控制器形成親近、安定的感覺；不做幼兒大頭比例。深褐蓬鬆短捲髮，沒有巨大護目鏡；眼睛略不對稱，思考時一邊眼會更瞇，嘴很小，看起來慢半拍但沒有傻笑。穿霧藍寬身圓領上衣、米白短背心、深棕錐形褲及圓鈍便鞋，少量琥珀黃集中在按鍵。袖子略長，操作時會先推起袖口。控制器是兩個大按鍵的扁方塊，手持或收在腰側；職業寵機另為掌心大小的低矮雙腳裝置，偏置天線與小指示燈，無笑臉，與故事收音機同伴分開設計。NULL會先檢查電池再判定設備報廢，對機器說話比對人自然；成長方向是敢向人開口求助。寵機可換模組，人物自己也必須有清楚剪影。

**四人共同檢查。** AKI方而穩、MILO長而鬆、PING窄而斜、NULL圓而收；差異不只靠髮色或衣服顏色。所有招牌裝置都是基本識別線索，不等於稀有專裝或唯一武器；可研究不同攻擊模式。手指、布料褶皺與配件均簡化，人物個性由小表情、重心和輪廓承擔。上述外形、色彩、髮型與性格均可在文字階段修改，未指定新本名、確切年齡或性別認同。

### 3. 角色與故事如何連起來

四人的共同目標是恢復街區各自的聲音，不新增末世或失蹤主線。每人以一項日常工作、一個性格矛盾、一個具體選擇建立人物感；少寫抽象口號。

建議短互動關係：AKI與小禾討論「直接修」還是「先查原因」；MILO與阿夏比對各店錄音；PING與阿澄核對班次／錯送訊息；NULL與修理攤檢查被誤判為報廢的設備。上述只是任務／對話提案，不預設師徒、親屬或戀愛關係。

每位玩家可單獨選任一職業完成現有六章，劇情不能要求四位主角同時在隊。四種視角可透過各章一兩句職業專屬回覆呈現，沿用原章節進度與獎勵，不新增四套任務狀態。配角依故事位置保持固定，避免同一人物在同時發生的情節中無解釋跨區出現。

NPC以工作姿態與單一道具辨認：小禾的檢修姿勢、阿澄的靠港站姿、阿夏的換帶動作、阿嶺的巡線查看動作。無名值班員可共用基礎骨架，以制服塊面與工具區分，不為每人做整套戰鬥動畫。

### 4. 再優化：讓造型、戰鬥與成長一致

**先處理的實作落差。** 03-combat目前四職業共用普攻時序與選敵流程。PING的「速度」首先指出手觀感，不能宣稱移速更快或普攻已變成遠程；NULL的「協作」指人與寵機，不代表多人隊伍或治療隊友。第一輪維持實際命中時刻、判定距離與冷卻，動畫對準既有命中，不為造型暗改玩法。

| 職業 | 必須看懂的自動循環 | 目前需驗證的弱點 | 首輪表現優化／後續能力候選 |
| --- | --- | --- | --- |
| AKI | 普攻接觸→短暫護盾→近距重擊及跳電 | 近身風險與小額護盾是否匹配；護盾屆滿是否容易被誤認為受傷 | 把站穩、命中與護盾首次生成分開；不能畫成持續無敵。若確有續戰弱點，先分析護盾覆蓋率與承傷，再評估調整，不先加坦克新機制。 |
| MILO | 持續命中→節拍累積→音波間隔縮短 | 轉場／追敵使3秒連段重置；是否看不出節奏成長 | 裝置律動隨真實節拍變化，清場後自然收拍。若中斷過密，再比較短暫保留與逐層衰減，二者均只是待測候選。 |
| PING | 普攻討伐→取得回執→下一輪連射增幅 | 無小怪首領戰缺少擊殺來源；外觀的遠程預期與共用普攻不符 | 區分基礎出手與職業連射，回執取得／消耗各一次短提示。若首領表現有缺口，再比較限頻弱點命中或持續命中換回執；不預先加入第二套觸發、標記操作或射程改制。 |
| NULL | 寵機攻擊→累積電池→修復；定期增幅 | 修復滿血溢出時看不出用途；寵機傷害與玩家攻擊來源混淆 | 讓寵機先於彈道做短動作；增幅與實際回復分開顯示，不顯示未發生的治療。先量測有效修復與輸出，再決定是否需要其他電池用途。 |

**成長的辨識規則。** 每職業先只做一個清楚的主循環，十二昇華表達三種取捨：AKI防護／清場／攻勢，MILO回放／控場／節奏，PING集中／分流／閃避，NULL雙核／修復／濺射。用同角色上的一項裝置模組、姿態或短特效區分，不製作十二套整人。可拆裝備改變局部造型，臉部、軀幹輪廓與基本站姿仍足以辨認職業；基本辨識不依賴稀有掉落。

**戰鬥讀圖優先級。** 敵人危險預警與角色受擊最高，其次為職業專技與被動觸發，最後才是裝飾待機。特效只讀既有狀態與事件，不另建假層數／計時器；低效果模式保留重要提示。四位專技可分別採折線、圓環、定向短線、寵機短脈衝；控制大小與持續時間，不能蓋過首領預警。像素臉的個性用於近景，遠景以身形與動作承擔辨識。

**先做三組公平比較。** 由同職業現行版與重製候選比較，再看跨職業差異；固定等級、敵人種子、場景、裝備／技能投資與測試時間，不要求四職業穿相同專裝。每組至少覆蓋多個敵人種子，紀錄清場時間、每分鐘討伐、承傷、倒下次數、專技次數、被動實際生效時間及浪費量，不能只用總DPS下結論。

1. 密集小怪：看清場與擊殺循環，避免PING只在已佔優勢時滾雪球。
2. 無小怪單體首領：看持續輸出與存活，分辨PING觸發機會、MILO連段和NULL修復價值。
3. 短戰鬥接轉場：看暖機／重置成本，確認AKI／MILO不被過度中斷。

各職業先要能完成同階必要內容，再比較擅長場景。能力調整只在來源紀錄與測試確認問題後，交原型討論串改既有owner；每次只改一組機制，另跑離線收益與存檔回歸。此輪尚未執行上述測試，不宣稱現行職業失衡。

**敘事再具體一點。** 每人用「一次會做的選擇」表現性格：AKI先隔離危險電源再修；MILO主動把自己的音量調低、留下別人的錄音；PING為核實收件人多走一段路；NULL先檢查電池與接點，拒絕直接報廢裝置。這些是新對話／短動作提案，沿用既有六章進度，不增加強制分支或改章節收益。任一角色都能獨立完成故事，NPC不與玩家職業重複成同一人物。

**選角期望要準確。** 每職業一句話依序說明主要手段與成長循環，再用同場景短預覽展示一次專技。選角不承諾尚未實作的遠程普攻、移速優勢或隊友治療；也不貼上沒有證據的最強／新手必選標籤。先完善文字與預覽規格，沿用原選角流程，不另做新介面。

### 構築與掛機優先（允許大改後的最新方向）

玩法架構統一見[玩法設計](game-design.md)的「永久構築與遠征發現」提案。使用者允許大改，四角色被動、職業名稱與昇華亦可重新設計；上方現行能力是基線，並非新版本不可變的規格。人物身份、機制候選與實際接入版本要分清。

- 角色提供不同起點與循環，不鎖定武器、元素或攻擊模式。同一角色要能支持至少兩種有明顯取捨的構築；招牌裝置不等於唯一可用武器。
- 身形／站姿保持身份，武器模組、投射方式與短特效表達當前構築；四角色美術不得阻礙分裂、直線、蓄能或裝置流派切換。
- 最新安排：使用者暫時不需要可玩樣板。先完成四人設定、輪廓探索、靜態風格預覽與三視圖；玩法樣板暫停，不作角色美術推進的前置條件。
- 新角色／道具解鎖擴充選擇，保留既有玩家投入；不把現有角色重新上鎖。現用模型與內嵌素材留到替換驗收後再移除。
- 玩家關注點是離線有收穫、回來可試新組合；人物故事以短互動連接發現與街區，避免長演出阻塞回訪。

### 5. 製作順序與驗收

1. **文字定義**：用本節完成四份簡短設計brief；明示哪些是現況、哪些是新提案，服裝／配色／性格對應玩法。
2. **四人同批輪廓探索**：在獨立素材目錄製作一致視角的小稿，同時檢查四人差異；不把圖片嵌入本文件。黑色剪影與去色後仍須能區分，普通裝備或卸下專裝後仍成立。
3. **單人風格樣板**：先以AKI測大色塊／像素臉／動作感，同時用NULL站位確認寵機不遮人；先用既有遊戲實際鏡頭及手機尺寸作小圖預覽，再判斷是否需要調整比例。
4. **四人三視圖**：正／側／背同尺度與中性站姿，另列臉部、招牌裝置與可拆件。單人基礎圖不混入浮游寵機，寵機另製，遊戲組合圖再驗位置。每人只保留目前採用版本及必要生成來源。
5. **低面數模型與動作**：優先相容現有16骨架、掛點與9動作名稱，四人各有動作節奏；新比例需檢查蒙皮、裝備握點與穿模。NPC共用簡化骨架；材質以純色unlit matte為主，五官只用小型像素圖。
6. **遊戲接入與回歸**：交原型討論串接入src/index/dist；逐步替換模型、頭像、選角圖與掛點，保留存檔鍵。驗收戰鬥／選角／裝扮的同一人物外形一致，舊存檔與裝備所有權正常；通過後才移除被替換資產。

初步模型預算以每主角約2,000–4,000三角面、1–2材質、可共用骨架作探索目標；不是已量測或強制承諾。先取得實際手機同場景的基線，再以畫面、幀時間、載入及記憶體結果調整，不為壓面數破壞剪影。像素邊緣由統一低解析渲染與nearest-neighbor放大形成，不將預先鋸齒畫進模型邊緣。

驗收重點：①去名／去色仍辨識四人；②遊戲縮小尺寸能讀招牌動作；③攻擊／施技／受傷／倒下狀態不混淆；④裝備與寵機不遮臉、不穿模；⑤沒有多餘手動操作或存檔改制。可先用5人小樣本做四選一辨識測試，以整體80%正確率作迭代門檻，並逐角看錯認組合；此為待測目標，不是目前已通過結果。
