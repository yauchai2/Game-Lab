# 有限構築、定向核心與城市終局

2026-10-22，v0.29.0。Alan 明確授權大改或重做，並要求落實有限天賦預算、核心定向取得及城市終局。承接 [深度藍圖](mechanics-depth-blueprint-2026-10-22.md)，本文件記錄實際規則，而非新增一輪候選規劃。

## 已改變的循環

玩家先在最多 36 點與兩個韌體之間取捨，再選擇要追求的核心與對應城市。遠征路段讓玩家選擇安全、輸出代價或碎片風險；永久保留發現及碎片，當局協定結束後移除。三區憑證開啟城市中樞，勝利推進最高八階，取得更高等級敵人與掉落。

沒有增加裝備欄或頂層導覽；入口在冒險的「城市遠征」，角色的核心收藏也有捷徑。美術、Cubic 像素字、銀灰掌機與藍紫 LCD 沿用既有設計。

## 天賦與韌體

- 路徑預算為 min（36，等級−1＋最深深度每四層的額外點）。100 節點保留，所有六個韌體都能在預算內到達，最多選兩個。
- 冷備份：即時技能傷害 ×0.85；冷啟動消耗凍結時產生生命 12% 的四秒緩衝盾，不疊加。盾先吸收角色傷害，切走韌體、遠征結束或測試離場都不保留測試盾。
- 三頻協定：三種元素同時啟用時技能傷害 ×1.3，暴擊率 −8%。
- 單頻放大：最多三種主動機件時技能傷害 ×1.35；停用整列／整欄／同元素共鳴，攻速 −15%。
- 超頻協定：急速 +25%，生命 −22%。
- 斷線重播：原始施放增加 60% 回放，技能傷害 ×0.85、攻速 −20%；次級事件不能再次安排回放或產電。
- 電池孤注：暴傷 +70%，每格電荷加成從 35% 提高到 45%，生命 −25%。

規則來源是 FIRMWARE／talentBudget／canAllocateTalent／calc；介面、戰鬥與預估共用。燃燒仍沿用原引擎的命中基礎，受技能命中基礎改變影響，沒有新增另一套持續傷害桶。

舊存檔不自動裁點或重配。原天賦、活動盤面／策略及三套配置另存 legacyTalent；保留舊制效果，城市入口暫停，其他遊戲繼續可玩。預覽顯示保留／移出數目及生命／直傷差異，確認後免費轉換為連通且合法的配置，原快照可還原。新裝備、庫存與進度不因還原丟失。

末端節點可免費退回，但不能切斷其餘路徑。原全盤洗點成本保留。城市／訓練期間不能變更天賦或切換整套構築。完整裝備配置快照不包含在本版；裝備仍共用。

## 三條城市與中樞

最深第八層及有限天賦開放城市。普通遠征不花地圖或門票，同時只能進行一個挑戰。敵人等級在出發時固定為 max（8，最深深度）＋2×（階級−1）。第一段 18 次擊殺，第二段 28 次，第三段為首領。

| 路線 | 實際題目 | 對應核心 |
| --- | --- | --- |
| 廢訊號網 | 移速 +30%、分散入場；首領重型預警間隔 2.5 秒 | 碎星球棒、撥號連線、訊號滿格 |
| 磁帶迴廊 | 最大生命 18% 護盾；三秒未受擊後每秒回充盾量 30%；持續命中或凍結阻止回充 | 回音光劍、電波外套、不滅羽絨 |
| 地下電源區 | 敵人傷害 +15%；承受傷害降低 25%，燃燒、電標記或凍結可解除 | 萬用遙控器、反光風褸、最後一通來電 |

每次首領在生命 65%／30% 時各提高移速 12%、縮短普通攻擊間隔 10% 並重新預警。沒有全免疫或反射。城市盾及冷備份使用青色短條，沿用既有投影血條，不新增後製 pass 或 Mesh 池。

兩次分岔可選旁路校準（敵人傷害 ×0.85、每秒回復生命 1%）、高壓快取（技能傷害 +18%、生命 −12%、下一段完成碎片 +1）或帶電捷徑（敵人傷害 ×1.15、移速 ×1.12、下一段完成碎片 +3）。代價與收益累加，只屬當次遠征。高風險額外碎片要完成下一段才領，立即撤離不能套取。

安全首階三段碎片為 3＋4＋7＝14。撤離／死亡只帶回已完成路段；首領未完成不發收尾獎勵及憑證。結算先標記 settled，再入永久碎片及清除 run，重複呼叫不能再領。返回普通冒險會解除原主線首領旗標，避免進入城市後主線卡住。

同階三區各一枚憑證開啟中樞；出發先扣，失敗不退。中樞前三段依序混合高速、護盾與重裝題目；勝利保證掉落出發時選定核心，並解鎖下一階，最高八階。憑證按階保存、沒有每日重置。重跑同階可繼續收集裝備與碎片。

## 定向取得及上班族契約

每區 24 枚碎片可合成一款該區未持有的核心，特殊效果與核心身分確定，詞綴仍隨機。生成等級為當時最深深度（至少八），加入核心收藏而不自動換裝；持有、點數、挑戰狀態在確認執行時重驗。兩次安全首階可跨過首次合成門檻；已持有核心不能反覆扣款。普通城市首領另有 15% 區域核心掉落機會，目標屬該區便掉目標，否則從區域池選擇。中樞保證當次指定核心，仍需角色走近拾取裝備。

出發時固定核心目標、離線選路策略、階級與敵人等級；之後改設定只影響下一次出發。前景分岔暫停戰鬥，給 15 秒手選，逾時依出發策略續行；離線直接照策略繼續。只完成當前遠征，死亡返回主線，不自動消耗其他地圖或憑證。

run 的路段、分支、暫存碎片及策略隨原 v2 存檔保存；新增 progressionVersion:1。重開會重建當前路段怪物，不保存首領剩餘生命，已結算路段不重發。無效城市 checkpoint 安全退回主線，不憑空補發碎片。

移除離線暗金禁令，守關者保底在線上及離線都推進；原六小時上限、75% 經驗及一般掉落 25% 折減保持。這不宣稱視覺 RNG 已分離或前後景逐幀完全一致；該部分仍在 DEP-C03。

訓練新增盾與生命的隔離：取消／結束清掉測試盾，存檔不能把入場人工補滿的生命帶出。另修正獨立 GridLab.dps 曾引用已刪除常數的問題，改用共用 LIMITS.repeatDamage。
