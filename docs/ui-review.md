# UI 與排版檢討（2026-10-20）

對照 Alan 提供的 11 張 UI 參考圖（Win98／XP 視窗、Y2K 個人網頁、3DS 主畫面、Windows Media Player 風格、乙女遊戲對話框）檢查目前版本。截圖為無頭 Chromium：桌機 1000x900、手機 430x900。

## 目前的問題

### 排版
- 更正：先前列的「手機按鈕列與數值被切掉、裝備卡溢出、桌機下方空白」是無頭 Chromium 的假象（視窗最小寬度 500px，截圖被裁成 430px；截圖高度也與視窗不一致）。改用 390px 寬的 iframe 重測後，手機直式沒有溢出。
- 真正的問題：HUD（等級、生命、深度、金幣）直接浮在天空上，沒有容器；手機上舞台周圍留白偏多；桌機舞台與底部卡片之間的比例還可以更緊湊。

### UI 風格（與參考圖的差距）
1. 參考圖的共通點是「視窗」：藍色漸層標題列、最小化／最大化／關閉鈕、凸起或凹陷的斜角邊框、灰底、選單列。現在的面板是圓角白卡，比較像手機 App，沒有桌面作業系統感。
2. 技能彈窗是整片白底加原生下拉選單，是最不像參考圖的地方。參考圖會用視窗 + 分頁 + 凹陷輸入框 + 凸起按鈕。
3. 背景只有天空與白雲，參考圖常把視窗疊在棋盤格或雲天上，並用多個小視窗堆疊出層次，目前沒有。
4. 對話與提示沒有統一容器：參考圖有黑底白字對話框（含心形圖示與進度格）、系統提示框（含 OK 按鈕與手形游標）。
5. 字型：中文內文可讀，但標題與數值沒有像素字或粗圓字的對比；參考圖的標題字（Lukky 的粗圓字、Fashion Fit 的粉紅描邊字）很有識別度。
6. 缺少裝飾元素：星星、愛心、貼紙、網點、狀態列（時間、訊號、電量）。3DS 畫面的青色外框與工作列也是可借用的語彙。

## 建議的改法（由大到小）
1. 先修排版 bug：手機按鈕列改成可橫向捲動或換行收進「選單」視窗；裝備卡手機改單欄可捲動；桌機把底部卡片改成固定高度的橫列，舞台佔滿剩餘高度。
2. 建一組共用的「作業系統視窗」元件：標題列漸層、三個視窗鈕、斜角邊框、內嵌凹陷區。裝備、技能、天賦盤、地圖、存檔全部用同一組。
3. 把 HUD 收進一個狀態列視窗（頂部：等級、經驗、生命、金幣、深度），仿 3DS 頂部狀態列與 Win 工作列。
4. 技能彈窗重做：視窗標題列 + 分頁，下拉選單換成自製的凹陷選單，寶石庫存用格子圖示而不是文字清單。
5. 背景改成雲天加棋盤格地板的延伸，彈窗後面保留模糊的遊戲畫面。
6. 加上一個黑底對話框，用在升級、掉寶、Boss 登場提示；加入星星、愛心、網點裝飾與底部工作列（存檔、速度、設定）。
7. 標題與數字用一套粗圓字，中文維持系統黑體，確保可讀。
