# 構築試玩室

Alan 要求把六個創意各做非常簡單的可玩 Demo，供親自比較。本目錄是獨立原型，不讀取正式遊戲 localStorage，不改 src/，數值不代表正式平衡。

試玩入口：https://yauchai2.github.io/Game-Lab/lab/buildcraft/

## 更新紀錄

### 0.1.0，2026-10-22

首次提供六種玩法：訊號接線台、戰鬥混音帶、超頻改機、頻道調諧、故障韌體、街區供能網。共用 30 秒清群／首領試跑、暫停、三倍速、範例、還原與文字戰報。

## 操作

- 接線台：點來源再點目的地；下方連線可拆除。感應器／電容單輸出、分線器雙輸出，分流守恆且禁止循環。
- 混音帶：點四拍之一，再選技能。冰凍／標記保留三秒，碎星消耗條件。
- 超頻：調時脈、開關武器及選散熱。100 熱量停機、降至 30 重啟。
- 調諧：每台發射器選四拍之一，共振破甲或錯拍減速。
- 韌體：兩插槽、五選項。先卸再裝；側射盲區與繞行、回聲與汲取可互相搭配。
- 城市：五點預算，只有經上下左右連回中樞的街區供能；孤立街區仍花預算。

進入即自動試跑；改動立即重新計時，暫停中修改則維持暫停。場景與每個玩法配置保留在頁面記憶體，重載清除。完成一局保留結果，供下一局比較。切換清群／首領會重新試跑；各場景分開記錄。背景分頁不補算。沒有持續儲存、正式掉落或離線獎勵。

## 實作與限制

engine.js 是規則與有效傷害／擊殺來源；app.js 只呈現及操作。固定 0.05 秒步長、相同敵人序列；最多 18 活敵、40 效果。360×180 Canvas 2D、最近鄰放大，不載入正式 3D 引擎、外部字體或圖片。介面採主專案色票，字體是原型用系統 fallback，不宣稱正式遊戲全套美術已完成。

六款是不同機制的探索，沒有按同一強度預算平衡，不能跨款比較總傷害排名。同一款內可以比較配置；更高傷害仍未必代表對群或生存較好。戰鬥以小型數值模型簡化了走位、範圍及護甲；繞行是相對位置原型，不是正式導航演算法。

## 發佈

先將來源提交及 push，再於 repo 根目錄執行 `python3 docs/prototypes/buildcraft/publish.py`。腳本只部署 index.html、style.css、engine.js、app.js 到 gh-pages 的 lab/buildcraft/，保留正式站所有檔案；明確核對根 index.html／version.json 的 blob 不變。正常 push 避免覆寫同時部署。研究、測試、截圖及文件不隨此腳本部署。

tools/publish_pages.py 的既有檔案允許清單新增這四個確切路徑，讓未來正式遊戲部署保留原型；沒有放寬至任意 docs/，也沒有重建或發佈正式遊戲。正式遊戲仍為 v0.31.0。
